Operaciones comunes ⚙️

✨

Crear

Botón derecho → Nuevo → Archivo/Carpeta. Nombra con claridad.

Ejemplo 2025-10-23_proyecto-v01

✏️

Renombrar

Windows F2 • macOS Enter.

Evita espacios dobles y caracteres raros.

📄

Copiar / Pegar

Ctrl+C / Ctrl+V • ⌘C / ⌘V

Duplica sin mover el original.

📤

Mover (Cortar / Pegar)

Ctrl+X / ⌘X para cambiar de ubicación.

También puedes arrastrar y soltar.

🗑️

Eliminar

Envia a Papelera. Vacíala periódicamente.

Cuidado con borrar sin respaldo.

📦

Comprimir .zip

Agrupa y reduce tamaño: botón derecho → Comprimir.

Ideal para enviar varias cosas juntas.

Mini-guía ilustrada

Dominar estas operaciones te ahorra tiempo y evita errores.
