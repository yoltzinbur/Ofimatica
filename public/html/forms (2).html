Formularios HTML

Aprende a crear formularios interactivos con HTML5

Introducción a los Formularios HTML

Los formularios HTML son una parte esencial de la web que permiten a los usuarios interactuar con sitios web. Se utilizan para recopilar información, realizar búsquedas, enviar comentarios y mucho más.

Un formulario HTML está compuesto por elementos de formulario como campos de texto, casillas de verificación, botones de opción, menús desplegables y botones de envío.

Ejemplo Básico de Formulario

<form>
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre">
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
  <button type="submit">Enviar</button>
</form>

Atributos de Formulario

Los formularios HTML tienen varios atributos que controlan su comportamiento y cómo se envían los datos.

Atributo Descripción Ejemplo
action Especifica dónde enviar los datos del formulario <form action="/procesar.php">
method Especifica el método HTTP para enviar los datos (GET o POST) <form method="post">
target Especifica dónde mostrar la respuesta (_blank, _self, _parent, _top) <form target="_blank">
autocomplete Habilita o deshabilita el autocompletado (on/off) <form autocomplete="off">
novalidate Especifica que el formulario no debe validarse al enviarse <form novalidate>

Consejo: Utiliza el método POST para enviar datos sensibles como contraseñas, ya que no se muestran en la URL como con GET.

Elementos de Formulario

Los formularios HTML contienen varios elementos que permiten diferentes tipos de interacción con el usuario.

Elemento Descripción Ejemplo
<input> Campo de entrada de datos (texto, contraseña, etc.) <input type="text">
<textarea> Área de texto multilínea <textarea rows="4"></textarea>
<select> Lista desplegable de opciones <select><option>Opción 1</option></select>
<button> Botón que puede enviar el formulario o realizar otras acciones <button type="submit">Enviar</button>
<label> Etiqueta para elementos de formulario <label for="nombre">Nombre:</label>
