Encabezados HTML

Los encabezados van de <h1> (más importante) a <h6> (menos importante). No se usan para “hacer el texto grande”: para el tamaño utiliza CSS. Los encabezados ayudan a usuarios y buscadores a entender la estructura del contenido.

Jerarquía recomendada

NivelUso típicoEjemplo
h1Título principal de la página (único en la mayoría de sitios)<h1>Guía HTML</h1>
h2Secciones principales<h2>Introducción</h2>
h3Subsecciones dentro de un h2<h3>Documento mínimo</h3>
h4Bloques dentro de un h3<h4>Doctype</h4>
h5Detalles<h5>Notas</h5>
h6Detalles mínimos<h6>Anexo</h6>

Estructura correcta vs incorrecta

Tamaños con CSS (no cambies el nivel por el tamaño)

Si quieres que un h3 “se vea grande”, hazlo con CSS, no cambiando a h1 por estética.

<style>
h3.destacado{ font-size:2rem; }
</style>
<h3 class="destacado">Subsección importante</h3>

Buenas prácticas, accesibilidad y SEO

  • Un h1 claro que resuma el propósito de la página.
  • No saltes niveles (de h2 pasa a h3, etc.).
  • No uses encabezados para dar estilo; usa CSS.
  • Los encabezados mejoran la navegación con lectores de pantalla (permiten saltar por niveles).
  • Incluye palabras clave naturales en encabezados, sin “stuffing”.
