Elementos de formulario

Los formularios se construyen con varios elementos especializados. Aquí tienes los más usados con su finalidad, un ejemplo copi able y una vista previa.

Resumen rápido

ElementoPara qué sirve
<input>Campo de entrada (texto, email, password, file, date, etc.).
<label>Etiqueta asociada a un control; mejora accesibilidad y área clicable.
<select>, <option>, <optgroup>Listas desplegables, opciones y agrupaciones.
<textarea>Entrada de texto multilínea.
<button>Botón de envío, reset o general.
<fieldset>, <legend>Agrupar controles con un título.
<datalist>Lista de sugerencias para un input.
<output>Resultado calculado (se puede actualizar con JS o con eventos).

<label> — Etiquetas accesibles

Usa for para enlazar con el id del control, o envuelve el control dentro del label.

<label for="user">Usuario</label>
<input id="user" name="user" type="text" required>

<label>Contraseña
  <input name="pass" type="password" required>
</label>

<input> — Campo de entrada

El elemento más versátil. El tipo se define con type (ver página Tipos de entrada).

<input type="text" name="nombre" placeholder="Tu nombre" required>
<input type="email" name="correo" placeholder="tucorreo@ejemplo.com" required>
<label><input type="checkbox" name="boletin"> Quiero recibir novedades</label>

<select>, <option> y <optgroup>

Listas desplegables. Usa option para cada valor y optgroup para agruparlos.

<label for="pais">País</label>
<select id="pais" name="pais" required>
  <option value="" disabled selected>Seleccione…</option>
  <optgroup label="América">
    <option value="mx">México</option>
    <option value="ar">Argentina</option>
  </optgroup>
  <optgroup label="Europa">
    <option value="es">España</option>
    <option value="fr">Francia</option>
  </optgroup>
</select>

<textarea> — Texto multilínea

<label for="msg">Mensaje</label>
<textarea id="msg" name="mensaje" rows="4" cols="30" placeholder="Escribe aquí…"></textarea>

<button> — Botones

Tipos principales: submit, reset y button.

<button type="submit">Enviar</button>
<button type="reset">Limpiar</button>
<button type="button" onclick="alert("Hola")">Solo botón</button>

<fieldset> y <legend> — Agrupar controles

<fieldset>
  <legend>Contacto</legend>
  <label for="nom">Nombre</label>
  <input id="nom" name="nombre" required>
  <label for="tel">Teléfono</label>
  <input id="tel" name="tel" type="tel">
</fieldset>
Contacto

<datalist> — Sugerencias

Proporciona opciones sugeridas mientras el usuario escribe en un input con list.

<label for="nav">Navegador</label>
<input list="browsers" id="nav" name="navegador" placeholder="Escribe...">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Edge">
  <option value="Safari">
</datalist>

<output> — Resultado

Muestra un valor calculado. Puede actualizarse con JS o usando el atributo oninput en un formulario.

<form oninput="res.value = Number(a.value) + Number(b.value)">
  <label>A: <input id="a" type="number" value="5"></label>
  <label>B: <input id="b" type="number" value="3"></label>
  = <output name="res" for="a b">8</output>
</form>
= 8
