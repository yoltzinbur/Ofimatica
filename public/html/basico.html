HTML básico

Repasemos las etiquetas más usadas: encabezados, párrafos, enlaces, imágenes, listas, saltos de línea y reglas horizontales, además de comentarios.

Encabezados

Los títulos van de <h1> (más importante) a <h6> (menos importante).

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Sección</h3>

Título principal

Subtítulo

Sección

Párrafos

Los párrafos se escriben con <p>. El navegador añade márgenes por defecto.

<p>Este es un párrafo.</p>
<p>Este es otro párrafo.</p>

Enlaces

Un enlace usa <a> con el atributo href. Para abrir en nueva pestaña, añade target="_blank" y rel="noopener".

<a href="https://www.example.com" target="_blank" rel="noopener">Visitar sitio</a>
Visitar sitio

demo

Imágenes

Una imagen se inserta con <img>. El atributo alt describe el contenido (accesibilidad).

<img src="img/foto.jpg" alt="Descripción de la imagen" width="300">

(Sustituye img/foto.jpg por tu archivo real.)

Listas

Listas desordenadas (<ul>) y ordenadas (<ol>) usan <li> para cada ítem.

Lista desordenada

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Lista ordenada

<ol>
  <li>Planear</li>
  <li>Desarrollar</li>
  <li>Publicar</li>
</ol>

Saltos de línea y regla horizontal

<br> crea un salto de línea; <hr> inserta una línea divisoria temática.

Línea 1<br>Línea 2<hr>Sección nueva
Línea 1
Línea 2
Sección nueva

Comentarios

Los comentarios no se muestran en la página y ayudan a documentar el código:

<!-- Esto es un comentario -->
<p>Contenido visible</p>
