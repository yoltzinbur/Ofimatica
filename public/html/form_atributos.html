Atributos de formulario

El elemento <form> admite diversos atributos que controlan a dónde y cómo se envían los datos, si se autocompletan, el charset, etc. Aquí verás los más importantes con ejemplos y vista previa.

Resumen

AtributoDescripciónEjemplo
actionURL de tu sitio a la que se envían los datos.action="procesar.html"
targetDónde abrir la respuesta: _self, _blank, _parent, _top o un nombre de iframe.target="_blank"
methodMétodo HTTP: get (URL) o post (cuerpo).method="post"
enctypeCodificación de los datos (solo con post): application/x-www-form-urlencoded (por defecto), multipart/form-data, text/plain.enctype="multipart/form-data"
autocompleteActiva/desactiva el autocompletado del navegador.autocomplete="on|off"
novalidateDesactiva la validación HTML5 para todo el formulario.novalidate
accept-charsetConjuntos de caracteres aceptados al enviar.accept-charset="UTF-8"
nameNombre del formulario (útil para scripts o asociar controles vía form).name="alta"

action

Define el destino al que se envían los datos del formulario.

<form action="gracias.html">
  <label for="q">Buscar</label>
  <input id="q" name="q" required>
  <button>Enviar</button>
</form>

target

Controla dónde se abre la respuesta al enviar el formulario.

<form action="gracias.html" target="_blank">
  <label for="correo">Correo</label>
  <input id="correo" name="email" type="email" required>
  <button>Enviar</button>
</form>

method y enctype

GET (parámetros en la URL)

<form action="buscar.html" method="get">
  <label for="s">Buscar</label>
  <input id="s" name="q" placeholder="término" required>
  <button>Buscar</button>
</form>

POST + archivos

Regla: para subir archivos usa method="post" y enctype="multipart/form-data".
<form action="subir.html" method="post" enctype="multipart/form-data">
  <label for="cv">CV (PDF):</label>
  <input id="cv" name="cv" type="file" accept="application/pdf" required>
  <button>Subir</button>
</form>

autocomplete

Permite al navegador sugerir y completar valores según el historial del usuario.

<form action="gracias.html" autocomplete="on">
  <label>Nombre: <input name="name" autocomplete="name"></label>
  <label>Correo: <input name="email" type="email" autocomplete="email"></label>
  <button>Enviar</button>
</form>

novalidate

Desactiva la validación nativa HTML5 del formulario (útil si validas tú mismo en JS o servidor).

Al usar novalidate, el navegador no mostrará mensajes ni bloqueará el envío aunque falten campos requeridos.
<form action="gracias.html" method="post" novalidate>
  <label>Email: <input name="email" type="email" required></label>
  <button>Enviar sin validar</button>
</form>

accept-charset

Especifica los conjuntos de caracteres permitidos al enviar. En la práctica, usa UTF-8 salvo que tengas requisitos especiales.

<form action="gracias.html" accept-charset="UTF-8">
  <label for="n">Nombre</label>
  <input id="n" name="nombre" required>
  <button>Enviar</button>
</form>

name

Da un nombre al formulario. Sirve para referenciarlo en scripts o para asociar controles externos mediante el atributo form.

<form id="f1" name="registro" action="gracias.html">
  <label>Usuario: <input name="user" required></label>
  <button>Enviar</button>
</form>

<!-- Control fuera del form, asociado por id -->
<label for="extra">Dato externo</label>
<input id="extra" name="extra" form="f1" placeholder="Se enviará con el form #f1">
