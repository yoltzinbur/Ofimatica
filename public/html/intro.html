Introducción a HTML

¿Qué es HTML?

HTML (HyperText Markup Language) describe la estructura de una página web mediante elementos (etiquetas) y atributos. Los navegadores leen el HTML y construyen el DOM para representarlo en pantalla.

Documento mínimo

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi página</title>
</head>
<body>
  <h1>¡Hola, HTML!</h1>
</body>
</html>

¿Qué hace cada elemento?

  • <!doctype html> — Indica que el documento usa **HTML5** y activa el modo estándar del navegador.
  • <html lang="es"> ... </html> — Elemento **raíz** de la página. El atributo lang="es" señala el idioma para accesibilidad y SEO.
  • <head> ... </head> — **Metadatos** del documento: codificación, viewport, título, enlaces a CSS/JS. Su contenido no se muestra en la página.
  • <meta charset="utf-8"> — Define la **codificación** como UTF-8 (soporta tildes, emojis, etc.). Evita caracteres “raros”.
  • <meta name="viewport" content="width=device-width, initial-scale=1"> — Hace que el diseño sea **responsivo** en móviles. Ajusta el ancho al del dispositivo y el zoom inicial a 1.
  • <title>Mi página</title> — **Título de la pestaña** y del resultado en buscadores. Debe ser único por documento.
  • <body> ... </body> — Contiene **todo lo visible** de la página: encabezados, párrafos, imágenes, enlaces, etc.
  • <h1>¡Hola, HTML!</h1> — **Encabezado principal** del contenido. Normalmente hay uno por página; no es el mismo que <title>.

Elementos, etiquetas y atributos

Un elemento suele usar etiqueta de apertura y cierre (<p>...</p>). Algunos no requieren cierre (<br>, <img>). Los atributos configuran el elemento (p. ej. lang="es", alt en imágenes).

Doctype

<!doctype html> indica que el documento usa HTML5 y activa el modo estándar del navegador. Escríbelo siempre al inicio.

Historia de HTML (línea de tiempo)

  1. 1989 Tim Berners-Lee propone la WWW
  2. 1991 Tim Berners-Lee publica HTML
  3. 1993 Borrador de HTML+ (Dave Raggett)
  4. 1995 HTML 2.0 (IETF/HTML WG)
  5. 1997 W3C Recomendación: HTML 3.2
  6. 1999 W3C Recomendación: HTML 4.01
  7. 2000 W3C Recomendación: XHTML 1.0
  8. 2008 Primer borrador público de HTML5 (WHATWG)
  9. 2012 WHATWG HTML Living Standard
  10. 2014 W3C Recomendación: HTML5
  11. 2016 Candidata: HTML 5.1
  12. 2017 W3C Recomendación: HTML5.1 (2ª ed.)
  13. 2017 W3C Recomendación: HTML5.2
