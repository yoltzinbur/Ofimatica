Editores HTML

Un editor de texto es la herramienta básica para escribir HTML. Evita procesadores de texto (Word, Pages) porque insertan formato oculto; utiliza editores pensados para código.

🧰

Qué editor usar

Para empezar, cualquier editor de texto sirve (Bloc de notas/TextEdit). Para trabajar cómodo, usa VS Code, Sublime Text o Notepad++ (Windows).

⚡

Por qué un editor de código

Resaltado de sintaxis, autocompletado, formato, vista en vivo y extensiones como Emmet aceleran tu flujo.

🧪

Prueba en el navegador

Guarda como .html y ábrelo en Chrome/Firefox/Edge. También puedes usar editores online para prototipos rápidos.

Paso a paso: tu primer archivo HTML

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola desde mi editor</h1>
</body>
</html>

VS Code: extensiones y atajos útiles

  • Emmet (incluido): abrevia y expande HTML. Escribe ! y pulsa Tab para obtener una plantilla básica.
  • Live Server: servidor local con recarga automática al guardar.
  • Prettier: formatea código de manera consistente (Configura “Format on Save”).
  • IntelliSense: sugerencias contextuales para etiquetas y atributos.

Buenas prácticas al editar

  • Usa UTF-8 (<meta charset="utf-8">) para tildes y emojis.
  • Guarda con extensión .html y nombra archivos en minúsculas/sin espacios.
  • Indenta y formatea: mejora la lectura y evita errores.
  • Evita procesadores de texto; siempre **editores de código**.
