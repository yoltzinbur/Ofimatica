Favicon HTML

El favicon es el ícono pequeño que aparece en la pestaña del navegador, marcadores y accesos directos. Se declara con una etiqueta <link rel="icon"> dentro de <head>.

Opción clásica: favicon.ico en la raíz

Muchos navegadores buscan /favicon.ico automáticamente. Aun así, es buena práctica enlazarlo explícitamente:

<link rel="icon" href="/favicon.ico" type="image/x-icon">

Recomendado: PNG con varios tamaños

Usa PNG por su calidad y transparencia. Provee al menos 16×16 y 32×32 px (y opcionalmente 48×48):

<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">

iOS / iPadOS (pantalla de inicio)

Para íconos al “Agregar a pantalla de inicio” en Apple, añade un apple-touch-icon (suele usarse 180×180):

<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

Manifest para PWA

Si tu sitio tiene manifest, enlázalo (define íconos adicionales y tema):

<link rel="manifest" href="/site.webmanifest">

Consejos de caché

  • Los navegadores cachan el favicon. Si no se actualiza, cambia el nombre del archivo (favicon-v2.png) o añade una query (?v=2).
  • Mantén tus archivos en la raíz (/) para rutas sencillas y compatibilidad.
  • Evita usar solo shortcut icon; hoy se usa simplemente rel="icon".

Ejemplo completo

<!-- En <head> -->
<link rel="icon" href="/favicon.ico" type="image/x-icon">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
Vista de ejemplo (representación). Tu favicon real se ve en la pestaña del navegador.
