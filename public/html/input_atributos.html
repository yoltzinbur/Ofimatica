Atributos de Entrada HTML

Aprende a utilizar los atributos de entrada para crear formularios más efectivos y accesibles

Introducción a los Atributos de Entrada

Los atributos de entrada HTML permiten controlar el comportamiento, apariencia y validación de los elementos de formulario. HTML5 introdujo numerosos atributos que mejoran significativamente la experiencia del usuario.

En esta guía, exploraremos los principales atributos de entrada y cómo utilizarlos para crear formularios más intuitivos y robustos.

Categorías de Atributos de Entrada

Atributos Básicos

name, value, placeholder

Atributos de Validación

required, pattern, min/max

Atributos de Comportamiento

disabled, readonly, autofocus

Atributos de UX

autocomplete, list, step

Atributos Principales de Entrada

Atributo Descripción Valores Ejemplo
name Nombre del elemento (importante para el envío de datos) texto <input name="usuario">
value Valor inicial del elemento texto/número <input value="valor predeterminado">
placeholder Texto de ejemplo que desaparece al escribir texto <input placeholder="Escribe aquí">
required Campo obligatorio antes de enviar (booleano) <input required>
disabled Desactiva el campo (booleano) <input disabled>
readonly Campo de solo lectura (booleano) <input readonly>
min / max Valores mínimo y máximo número/fecha <input min="1" max="100">
pattern Expresión regular para validación regex <input pattern="[A-Za-z]{3}">
autocomplete Controla el autocompletado on/off <input autocomplete="off">
autofocus Enfoca el campo automáticamente (booleano) <input autofocus>
step Intervalo para campos numéricos número <input step="5">
list Lista de opciones predefinidas id de datalist <input list="opciones">

Demostración Interactiva de Atributos

Formulario Completo con Diferentes Atributos

5
<form id="advancedForm">
  <input type="text" name="fullname" required placeholder="Tu nombre completo" autocomplete="name">
  <input type="email" name="user-email" required autocomplete="email">
  <input type="number" name="user-age" min="18" max="120" required>
  <input type="tel" name="user-phone" pattern="[0-9]{9}">
  <input type="text" name="user-country" list="country-list">
  <input type="range" name="user-rating" min="1" max="10" step="1">
  <input type="password" name="user-password" minlength="8" autocomplete="new-password">
</form>
