Ejemplos de HTML Interactivos

A continuación encontrarás ejemplos básicos de etiquetas HTML que puedes editar y probar en tiempo real.

1. Encabezados

Los encabezados definen niveles de títulos desde <h1> (más importante) hasta <h6>.

2. Párrafos y formato de texto

Los párrafos se escriben con <p> y puedes usar <strong> (negrita) o <em> (cursiva).

3. Enlaces

Los enlaces se crean con <a> y se pueden abrir en otra pestaña con target="_blank".

4. Imágenes

Las imágenes se insertan con <img> y deben tener los atributos src (fuente) y alt (texto alternativo).

5. Listas

HTML permite listas ordenadas (<ol>) y no ordenadas (<ul>).

6. Tabla simple

Una tabla usa las etiquetas <table>, <tr>, <th> y <td>.

7. Formulario básico

Los formularios recogen información del usuario mediante diferentes tipos de entrada.
