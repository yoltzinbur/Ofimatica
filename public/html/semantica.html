Semántica HTML

Los elementos semánticos describen el propósito del contenido y ayudan a navegadores, lectores de pantalla y motores de búsqueda a entender la estructura de una página.

Elementos clave

  • <header> encabezado de una página o sección.
  • <nav> navegación principal o conjunto de enlaces.
  • <main> contenido principal único del documento.
  • <section> sección temática del documento.
  • <article> contenido independiente y reutilizable.
  • <aside> contenido complementario (barras laterales, notas).
  • <footer> pie de página o de sección.
  • <figure> unidad visual con <figcaption> como pie.
  • <details> área desplegable con <summary> como título.

Plantilla de layout semántico

<header>Cabecera</header>
<nav>Enlaces</nav>
<main>
  <section>
    <article>Artículo 1</article>
    <article>Artículo 2</article>
  </section>
  <aside>Barra lateral</aside>
</main>
<footer>Pie</footer>
<aside>
Enlaces, publicidad o bloques auxiliares.
<main>

Contiene <section> y <article> con el contenido central.

Medios con pie: <figure> y <figcaption>

<figure>
  <img src="img/paisaje.jpg" alt="Valle al atardecer" width="480" height="270">
  <figcaption>Figura 1. Valle al atardecer.</figcaption>
</figure>

Contenido desplegable: <details> / <summary>

<details>
  <summary>Más información</summary>
  <p>Texto adicional que el usuario puede mostrar/ocultar.</p>
</details>
Más información

Texto adicional que el usuario puede mostrar/ocultar.

Buenas prácticas

  • Usa un único <main> por página.
  • No utilices elementos semánticos solo por estilo; su significado importa.
  • Combina semántica con roles/atributos ARIA solo cuando sea necesario.
  • Incluye alt descriptivo en imágenes dentro de <figure>.

Mini cuestionario

1) ¿Qué elemento debe aparecer **una sola vez** y contener el contenido principal?
2) ¿Qué elemento agrupa un medio con su pie explicativo?
3) ¿Qué etiqueta es adecuada para una barra lateral?
