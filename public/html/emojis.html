Emojis HTML

Los emojis son caracteres Unicode. En HTML se muestran directamente con UTF-8 o con códigos numéricos (decimal o hexadecimal).

Imprescindible: incluye <meta charset="utf-8"> en Encabezado HTML para que los emojis se vean correctamente.

Formas de insertar emojis

😀 Hola!
😀 Hola!
&#128512; Hola!  <!-- U+1F600 -->
😀 Hola!
&#x1F603; Bien!  <!-- U+1F603 -->
😃 Bien!

Modificadores: tono de piel y secuencias

Algunos emojis aceptan modificadores (p. ej., Fitzpatrick para tono de piel) o se combinan con ZWJ (Zero-Width Joiner) para formar secuencias: 👨‍💻, 👩🏽‍🔧, etc.

👍 👍🏻 👍🏽 👍🏿
👍 👍🏻 👍🏽 👍🏿
👨‍💻  <!-- U+1F468 ZWJ U+1F4BB -->
👨‍💻

Compatibilidad: La apariencia de los emojis depende del sistema/fuente del usuario. Si un emoji no existe, puede verse como ☐ o ❓. Mantén textos alternativos cuando sea necesario.

Buenas prácticas

  • Usa UTF-8 y guarda tus archivos en ese formato.
  • Para contenido crítico, no dependas solo del emoji: acompáñalo de texto (<span aria-hidden="true">✅</span> Aprobado).
  • En atributos/JS, prefiere códigos escapados si hay problemas de codificación (&#x1F680; en lugar de 🚀 literal).
  • Evita usar emojis como únicos indicadores de estado/acción; añade title o texto visible.
