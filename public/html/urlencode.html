Codificación de URL (URL Encoding)

La codificación de URL —también llamada percent-encoding— convierte caracteres no seguros en una representación segura usando % seguido de su valor hexadecimal en UTF-8. Ej.: un espacio se codifica como %20.

Cuándo codificar: siempre que pongas texto del usuario o caracteres especiales en una URL (ruta, query, fragmento). Evita construir URLs "a mano".

Ejemplo rápido

<!-- Texto con espacios y acentos -->
<a href="buscar.html?q=Café con leche&origen= móvil">Buscar</a>

<!-- Versión codificada -->
<a href="buscar.html?q=Caf%C3%A9%20con%20leche&origen=%20m%C3%B3vil">Buscar (segura)</a>

Original: q=Café con leche&origen= móvil

Codificada: q=Caf%C3%A9%20con%20leche&origen=%20m%C3%B3vil

Caracteres reservados más comunes

CarácterUsoCodificado
spaceSeparador no válido%20 (en formularios puede ser +)
#Inicio de fragmento%23
?Inicio de query%3F
&Separador de parámetros%26
=Asignación en query%3D
%Indicador de codificación%25
/Separador de ruta%2F (si es parte de un segmento)
:Esquema/host/puerto%3A (si aparece en datos)
+En x-www-form-urlencoded: espacio%2B (si quieres un «+» literal)

Espacios: %20 vs + — En el estándar de URL el espacio es %20. En el formato de formularios application/x-www-form-urlencoded se usa + para espacios en la query. Ambos son comunes; sé consistente.

JavaScript: funciones para codificar

  • encodeURI(url): codifica una URL completa pero no codifica :/?#&= (necesarios para la estructura).
  • encodeURIComponent(valor): codifica un componente (por ejemplo, el valor de un parámetro). Úsala para query params.
// Construir query segura
const params = new URLSearchParams({
  q: "Café con leche",
  origen: "móvil+web"
});
const url = "/buscar.html?" + params.toString();
// "/buscar.html?q=Caf%C3%A9+con+leche&origen=m%C3%B3vil%2Bweb"
console.log(url);
// Diferencia entre encodeURI y encodeURIComponent
const base = "https://ejemplo.com/buscar?q=";
const valor = "c++ guía #1";
// ❌ Incorrecto: deja caracteres peligrosos en el valor
console.log(base + encodeURI(valor));
// ✅ Correcto para parámetros:
console.log(base + encodeURIComponent(valor));

Formulario: envío application/x-www-form-urlencoded

Al enviar un formulario con método GET o POST (por defecto), el navegador codifica el cuerpo/URL usando este formato: pares clave=valor unidos por &, espacios como + y otros caracteres con %xx.

<!-- Ejemplo de formulario -->
<form action="/buscar.html" method="get">
  <label>Búsqueda: <input name="q" value="Café con leche"></label>
  <button>Enviar</button>
</form>
<!-- URL resultante (aprox.): /buscar.html?q=Caf%C3%A9+con+leche -->

Buenas prácticas

  • Usa encodeURIComponent para valores de parámetros; encodeURI para la URL completa.
  • Para construir URLs, preferir URL y URLSearchParams.
  • No dupliques codificación (evita terminar con %2520 en vez de %20).
  • Mantén las URL legibles; codifica solo lo necesario.

Ojo: si pegas una URL ya codificada dentro de otra función de codificación, terminarás con caracteres doblemente codificados (ej. %252F). Decodifica con decodeURIComponent si es necesario.
