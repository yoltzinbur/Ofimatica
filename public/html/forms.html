Formularios HTML

Un <form> recopila datos del usuario y los envía al servidor. Los atributos más usados son action, method, target, enctype, autocomplete, name, novalidate y accept-charset.

Plantilla básica

<!-- action: a una página de TU sitio -->
<form action="gracias.html" method="get" autocomplete="on">
  <label for="q">Buscar:</label>
  <input id="q" name="q" type="search" placeholder="Escribe tu búsqueda" required>
  <button type="submit">Enviar</button>
</form>

Atributos de <form>

AtributoDescripciónEjemplo
actionURL (de tu propio sitio) a la que se enviarán los datos.action="procesar.html"
methodMétodo HTTP: get (parámetros en la URL) o post (cuerpo de la petición).method="post"
targetDónde abrir la respuesta: _self, _blank, _parent, _top o un nombre de iframe.target="_blank"
enctypeCodificación de datos (solo con method="post"). Por defecto application/x-www-form-urlencoded.enctype="multipart/form-data"
autocompleteActiva o desactiva el autocompletado del navegador.autocomplete="on|off"
nameNombre del formulario (útil en JS y para asociar controles con el atributo form).name="login"
novalidateDesactiva la validación nativa HTML5 del formulario.novalidate
accept-charsetConjuntos de caracteres aceptados. Normalmente basta con UTF-8.accept-charset="UTF-8"

Métodos y envío

GET (parámetros en la URL)

<form action="gracias.html" method="get">
  <label for="q2">Buscar</label>
  <input id="q2" name="q" placeholder="Escribe tu búsqueda" required>
  <button>Buscar</button>
</form>

Útil para búsquedas, filtros y acciones que pueden compartirse como URL.

POST (datos en el cuerpo)

<form action="procesar.html" method="post">
  <label for="correo">Correo</label>
  <input id="correo" name="email" type="email" required>
  <button>Enviar</button>
</form>

Preferido para datos sensibles o grandes (no quedan en la URL).

Tipos de codificación (enctype)

ValorUso
application/x-www-form-urlencoded (por defecto)Convierte espacios a + y escapa caracteres; adecuado para la mayoría de formularios.
multipart/form-dataObligatorio para subir archivos con <input type="file">.
text/plainEnvía texto sin codificar; raramente recomendado.
Regla de oro: para subir archivos usa method="post" + enctype="multipart/form-data".

Controles habituales

Texto y contraseña

<label for="user">Usuario</label>
<input id="user" name="user" type="text" autocomplete="username" required>
<label for="pass">Contraseña</label>
<input id="pass" name="pass" type="password" autocomplete="current-password" minlength="6" required>

Radios y checkboxes

<!-- mismo name agrupa radios -->
<label><input type="radio" name="genero" value="m" required> Masculino</label>
<label><input type="radio" name="genero" value="f"> Femenino</label>
<label><input type="checkbox" name="tyc" required> Acepto Términos</label>

Select / Optgroup

<label for="pais">País</label>
<select id="pais" name="pais" required>
  <option value="">Seleccione…</option>
  <optgroup label="América">
    <option value="mx">México</option>
    <option value="ar">Argentina</option>
  </optgroup>
</select>

Textarea

<label for="msg">Mensaje</label>
<textarea id="msg" name="mensaje" rows="4" cols="30" placeholder="Escribe aquí…"></textarea>

Datalist (sugerencias)

<label for="navegador">Navegador</label>
<input list="browsers" id="navegador" name="navegador">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Edge">
</datalist>

Output (resultado calculado)

<form oninput="res.value = parseInt(a.value||0) + parseInt(b.value||0)">
  <input id="a" type="number" value="2"> +
  <input id="b" type="number" value="3"> =
  <output name="res" for="a b">5</output>
</form>

Asociación de etiquetas

  • Explícita: <label for="idDelInput"> se vincula con el id del control.
  • Implícita: envolver el control dentro del <label>...</label>.
  • Usa fieldset y legend para agrupar y dar contexto.
<fieldset>
  <legend>Contacto</legend>
  <label for="nom">Nombre</label>
  <input id="nom" name="nombre" required>
</fieldset>

Atributos form* (en controles)

Algunos atributos permiten definir comportamiento de envío por control, incluso si el control está fuera del formulario.

AtributoQué haceEjemplo
formAsocia un control a un formulario por id.<input form="f1">
formactionURL de envío alternativa para ese botón/submit.<button formaction="buscar.html">
formenctypeCodificación alternativa.<button formenctype="multipart/form-data">
formmethodMétodo alterno (get/post).<button formmethod="get">
formnovalidateEvita validar al enviar con ese botón.<button formnovalidate>
formtargetDestino alterno (_blank, etc.).<button formtarget="_blank">
 
<form id="buscador" action="gracias.html" method="post">
  <label>Correo: <input type="email" name="email" required></label>
  <button type="submit">Enviar (POST)</button>
  <button type="submit" formmethod="get" formaction="buscar.html">Buscar (GET)</button>
</form>

<!-- input FUERA del form, asociado por id -->
<label for="q-ext">Consulta externa:</label>
<input id="q-ext" name="q" form="buscador" placeholder="Se enviará con el formulario #buscador">

Botones

<button type="submit" name="accion" value="enviar">Enviar</button>
<button type="reset">Limpiar</button>
<button type="button" onclick="alert("Solo acción local")">Solo botón</button>

Validación HTML5

  • Requeridos: required.
  • Rangos y longitudes: min/max, minlength/maxlength.
  • Patrones: pattern (expresión regular).
  • Tipos con validación integrada: email, url, number, date, etc.
  • Desactivar validación del formulario: novalidate o por botón con formnovalidate.
<form action="gracias.html" method="post">
  <label>Email: <input name="email" type="email" required></label>
  <label>Teléfono: <input name="tel" type="tel" pattern="[0-9]{10}" placeholder="10 dígitos"></label>
  <button>Enviar</button>
</form>
