División HTML (<div>)

<div> es un elemento de bloque que se usa para agrupar otros elementos y aplicar estilos con CSS o scripts con JavaScript. No aporta significado semántico por sí mismo (usa elementos semánticos cuando sea posible).

Sintaxis básica

<div>
  <h2>Sección</h2>
  <p>Contenido dentro del div.</p>
</div>

Sección

Contenido dentro del div.

Con class (reutilizable)

Usa clases cuando quieras el mismo estilo en varios elementos.

<div class="caja">A</div>
<div class="caja">B</div>
<style>
.caja{border:1px solid #cbd5e1;padding:.5rem;border-radius:.5rem}
</style>
A
B

Con id (único)

Usa id para identificar un único elemento del documento.

<div id="banner">Bienvenido</div>
<style>
#banner{background:#2563eb;color:#fff;padding:.65rem 1rem;border-radius:.5rem}
</style>
Bienvenido

Maquetación con div + CSS

Aunque existen etiquetas semánticas (header, nav, main, aside, footer), a veces se combinan div con grid/flex para estructurar.

<div class="layout">
  <div class="sidebar">Menú</div>
  <div class="content">Contenido principal</div>
</div>
Menú
Contenido principal

Ejemplo de tarjetas

<div class="cards">
  <div class="card"><h3>Producto A</h3><p>Descripción corta.</p></div>
  <div class="card"><h3>Producto B</h3><p>Otra descripción.</p></div>
</div>

Producto A

Descripción corta.

Producto B

Otra descripción.

Buenas prácticas

  • Prefiere etiquetas semánticas cuando describan mejor el contenido.
  • Evita el “divitis”: demasiados div sin necesidad.
  • Usa nombres de clase claros (p. ej., .sidebar, .card).
  • Recuerda que <div> es de bloque; para marcar texto en línea usa <span>.
