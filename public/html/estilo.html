Guía de estilo HTML

Reglas y convenciones para escribir HTML5 limpio, válido y accesible.

1) Doctype y estructura mínima

Comienza siempre con el doctype HTML5 y define el idioma del documento.

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Título de la página</title>
</head>
<body>
  <main>Contenido…</main>
</body>
</html>

2) Reglas de sintaxis esenciales

  • Escribe etiquetas y atributos en minúsculas.
  • Incluye comillas para todos los valores de atributos (class="card").
  • Cierra las etiquetas que lo requieran (p. ej. <li>, <p>, <div>).
  • Usa lang en <html> y meta charset="utf-8" al inicio del <head>.
  • Evita atributos obsoletos (align, bgcolor, border): usa CSS.
  • Mantén una indentación consistente (2 o 4 espacios; no mezcles).
  • Prefiere estructura semántica (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>).

3) Elementos vacíos (void elements)

Son elementos que no llevan etiqueta de cierre ni contenido.

  • <area>
  • <base>
  • <br>
  • <col>
  • <embed>
  • <hr>
  • <img>
  • <input>
  • <link>
  • <meta>
  • <source>
  • <track>
  • <wbr>
Nota: No uses “auto-cierre” tipo <br /> en HTML5 (es válido pero innecesario).

4) Atributos

4.1 Atributos booleanos

Se escriben solo con el nombre del atributo.

✅ Correcto

<input type="checkbox" checked>
<button disabled>Enviar</button>

❌ Incorrecto

<input type="checkbox" checked="true">
<button disabled="disabled">Enviar</button>

4.2 Atributos globales útiles

  • id, class, style, title, hidden, tabindex, data-*.
  • Usa id único por página y class para estilos/reutilización.

5) Anidación y contenido

  • No anides bloques dentro de <p>. Cierra el párrafo antes de abrir <div>, <section>, etc.
  • Mantén el orden lógico de encabezados: h1 → h2 → h3…
  • Incluye texto alternativo en imágenes (alt) y asocia <label for> con controles de formulario.

✅ Anidación válida

<p>Introducción.</p>
<section>
  <h2>Detalles</h2>
  <p>Texto de la sección.</p>
</section>

❌ Anidación inválida

<p>Introducción
  <section>...</section>
</p>

6) Comentarios y legibilidad

<!-- Esta sección lista los planes -->
<section id="planes">...</section>
  • Usa comentarios breves y útiles; evita comentar código obvio.
  • Una etiqueta por línea cuando tenga muchos atributos; alinea y agrupa secciones relacionadas.

7) Recursos externos: CSS y JavaScript

CSS

<link rel="stylesheet" href="assets/style.css">

JS

Usa defer para ejecutar tras el parseo del HTML.

<script defer src="assets/app.js"></script>

8) Plantilla semántica base

<header>...</header>
<nav>...</nav>
<main>
  <article>...</article>
  <aside>...</aside>
</main>
<footer>...</footer>

9) Ejemplos “bien vs mal”

✅ Correcto

<img src="img/paisaje.jpg" alt="Valle al atardecer" width="640" height="360">

❌ Incorrecto

<IMG SRC=paisaje.JPG ALT=Foto align=center>
