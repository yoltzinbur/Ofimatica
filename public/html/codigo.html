Código de computadora HTML

Para marcar código, entradas de teclado y salidas de programa, HTML ofrece etiquetas semánticas que mejoran la legibilidad y la accesibilidad.

<code> — fragmentos de código

Se usa para pequeñas porciones en línea. Para conservar saltos y espacios, combínalo con <pre>.

Ponga <code>const saludo = 'Hola';</code> para resaltar.
Ejemplo: Ponga const saludo = 'Hola'; para resaltar.

<pre> + <code> — bloques con formato

<pre> preserva espacios y saltos de línea.

<pre><code>
function suma(a, b) {
  return a + b;
}
console.log(suma(2, 3));
</code></pre>
function suma(a, b) {
  return a + b;
}
console.log(suma(2, 3));

<kbd> — entrada del usuario

Representa teclas o combinaciones: Ctrl + S.

Presiona <kbd>Ctrl</kbd> + <kbd>S</kbd> para guardar.
Presiona Ctrl + S para guardar.

<samp> — salida de programa

Para respuestas o mensajes devueltos por un sistema.

<p>Salida: <samp>Archivo guardado correctamente.</samp></p>
Salida: Archivo guardado correctamente.

<var> — variables

Marca nombres de variables o parámetros en expresiones.

El área es <var>b</var> × <var>h</var>.
El área es b × h.

Buenas prácticas

  • Usa <code> para fragmentos en línea y <pre> para bloques.
  • <kbd> para acciones del usuario; <samp> para salidas.
  • <var> ayuda a distinguir parámetros/variables en documentación técnica.
  • Añade contraste suficiente y fuente monoespaciada para legibilidad.
