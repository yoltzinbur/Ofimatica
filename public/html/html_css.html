Usar CSS con HTML

CSS (Cascading Style Sheets) controla la presentación: colores, tamaños, espaciados, tipografías, layout, etc. Hay tres maneras principales de aplicarlo:

1) Estilos en línea (inline)

Se usan en el atributo style de una etiqueta. Útil para demos, pero no recomendado en proyectos grandes.

<p style="color:tomato;font-weight:bold">Texto en rojo y en negrita</p>

2) Hoja de estilo interna (<style>)

Se define en la cabecera del documento y afecta a la página actual.

<head>
  <style>
    h1{ color:#1e293b }
    .btn{ background:#16a34a; color:#fff; padding:.5rem 1rem; border-radius:.5rem }
  </style>
</head>

3) Hoja de estilo externa (recomendada)

Enlaza un archivo .css separado que puedes reutilizar en muchas páginas.

<head>
  <link rel="stylesheet" href="styles.css">
</head>

Sintaxis básica de CSS

selector { propiedad: valor; otra-propiedad: otro-valor; }
/* Ejemplo */
p { color:#0f172a; line-height:1.6 }
.destacado { background:gold }
#cabecera { border-bottom:2px solid #e2e8f0 }

Propiedades frecuentes

Color y tipografía

p { color:#334155; font-family: Arial, Helvetica, sans-serif; font-size:16px }

Espaciado

.box { margin:16px; padding:12px }

Bordes y fondo

.panel { border:2px dashed #94a3b8; background-color:#f8fafc; border-radius:10px }

Cascada y especificidad (mini resumen)

  • La “C” de CSS es Cascading: el último estilo compatible suele ganar.
  • La especificidad decide empates: id > clase > etiqueta > universal.
  • Evita el uso de !important salvo casos puntuales.

Ejemplo completo

<style>
  .card-demo{border:1px solid #e5e7eb;padding:1rem;border-radius:.75rem}
  .card-demo h3{margin:0 0 .5rem;color:#0f172a}
  .card-demo .btn{background:#2563eb;color:#fff;padding:.4rem .8rem;border-radius:.5rem}
</style>

<div class="card-demo">
  <h3>Producto</h3>
  <p>Texto descriptivo…</p>
  <button class="btn">Comprar</button>
</div>
