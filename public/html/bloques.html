Bloque e Inline

En HTML, los elementos tienen un comportamiento de visualización por defecto: de bloque (ocupan todo el ancho y empiezan en línea nueva) o en línea (solo ocupan su contenido y no fuerzan salto de línea).

Elementos de bloque

Ejemplos: <div>, <p>, <h1..h6>, <ul>/<ol>, <table>, <header>, <section>, <footer>, <form>.

<div>Caja A</div>
<div>Caja B</div>
Caja A (bloque)
Caja B (bloque)

Elementos en línea

Ejemplos: <span>, <a>, <strong>, <em>, <img>, <code>, <label>, <input>.

Texto <span>uno</span> y <span>dos</span> en la misma línea.
Texto uno y dos en la misma línea. enlace

Cambiar el flujo con CSS

Cualquier elemento puede cambiarse con la propiedad display (por ejemplo, para crear botones en línea o bloques clicables).

Inline → Block

<a href="#" class="btn-block">Abrir</a>
<style>.btn-block{display:block;padding:.5rem 1rem;background:#2563eb;color:#fff;text-decoration:none;border-radius:.4rem}</style>
Abrir

Block → Inline

<div class="chip">Etiqueta</div>
<style>.chip{display:inline;padding:.2rem .5rem;border:1px solid #94a3b8;border-radius:999px;background:#f8fafc}</style>
Etiqueta
UI

Elementos en línea pero “reemplazados”

<img>, <input>, <textarea>, <select> son inline pero su caja proviene de un recurso/controles (se comportan distinto al texto).

Buenas prácticas

  • Usa div para agrupar bloques y span para marcar texto en línea sin significado semántico.
  • Prefiere elementos semánticos (header, nav, section, article, footer) cuando correspondan.
  • No abuses de cambiar display si existe un elemento más adecuado.
