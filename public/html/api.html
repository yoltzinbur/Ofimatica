API web HTML (resumen)

HTML5 introdujo muchas APIs (Application Programming Interfaces) que permiten a las páginas web interactuar con el navegador, los dispositivos y los datos del usuario sin depender de plugins externos.

📍

Geolocation API

Permite obtener la ubicación del usuario (con su permiso). Ideal para mapas o servicios basados en ubicación.

💾

Web Storage API

Guarda datos en el navegador con localStorage o sessionStorage, reemplazando las cookies tradicionales.

🎤

Media API

Permite acceder a la cámara o micrófono del dispositivo para aplicaciones multimedia o videollamadas.

Otras APIs importantes

  • Canvas API: para dibujar gráficos y animaciones en 2D.
  • Drag and Drop API: permite arrastrar y soltar elementos dentro del navegador.
  • Web Workers API: ejecuta procesos en segundo plano sin bloquear la interfaz.
  • WebSockets API: permite comunicación en tiempo real con el servidor.
  • History API: controla la navegación y el historial del navegador.

Ejemplo: obtener ubicación con Geolocation

navigator.geolocation.getCurrentPosition(function(pos) {
  alert("Latitud: " + pos.coords.latitude);
});

Seguridad y permisos

Algunas APIs requieren permisos del usuario y solo funcionan en sitios seguros (HTTPS). El navegador solicitará consentimiento antes de acceder a la ubicación, cámara o micrófono.
