Estilos HTML

En HTML puedes aplicar estilos rápidos con el atributo style. En proyectos reales, es mejor mover esos estilos a CSS (interno o externo), pero el atributo es útil para ejemplos puntuales.

El atributo style

La sintaxis es style="propiedad: valor;". Puedes incluir varias declaraciones separadas por ;.

<p style="color: blue; background-color: #f0f8ff;">Texto con color y fondo.</p>

Propiedades comunes

Color y fondo

<p style="color: crimson;">Texto rojo</p>
<p style="background-color: lightgoldenrodyellow;">Fondo suave</p>

Fuente y tamaño

<p style="font-family: Arial, Helvetica, sans-serif; font-size: 18px;">Fuente y tamaño</p>

Alineación, borde y espaciado

<div style="text-align:center; border:1px solid #d1d5db; padding:.5rem; margin:.5rem 0;">Caja centrada</div>

Múltiples estilos en una misma etiqueta

<h2 style="color:#0ea5e9; font-size:28px; text-align:center; background:#eef6ff; padding:.5rem; border-radius:.5rem;">Encabezado estilizado</h2>

Valores de color

Puedes escribir colores como nombres, hex, RGB o HSL:

FormaEjemploVista
Nombrecolor: tomato;tomato
Hex#16a34a#16a34a
RGBrgb(14,165,233)rgb(14,165,233)
HSLhsl(200 98% 39%)hsl(200 98% 39%)

Inline vs. CSS (recomendado)

Para mantener el HTML limpio y reutilizable, usa CSS en lugar de muchos style="":

Inline (rápido, no escalable)

<p style="color:#0b1324; background:#eef6ff; padding:.4rem .6rem;">Estilo inline</p>

Con clase CSS (preferido)

<!-- HTML -->
<p class="chip">Con clase</p>

<!-- CSS -->
.chip{ color:#0b1324; background:#eef6ff; padding:.4rem .6rem; border-radius:.5rem }

Buenas prácticas

  • Usa clases y CSS externo para proyectos reales; deja el inline para demos puntuales.
  • Escribe propiedades en kebab-case (font-size, background-color).
  • Separa las declaraciones con ; y no olvides los valores con unidades cuando aplique (px, rem, %).
  • Evita estilos inline en elementos repetidos; complica el mantenimiento.
