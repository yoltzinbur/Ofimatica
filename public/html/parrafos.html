Párrafos HTML

El elemento <p> define un párrafo. Los navegadores añaden margen antes y después de cada párrafo para separarlos visualmente.

Crear párrafos

<p>Este es el primer párrafo.</p>
<p>Este es el segundo párrafo.</p>

Colapso de espacios en HTML

Varios espacios o saltos de línea en el HTML se colapsan en un único espacio al mostrarse. Si necesitas mantener espacios y saltos tal cual, usa <pre>.

Texto normal (colapsa)

<p>Hola       mundo
con   múltiples   espacios.</p>

Render: Hola mundo con múltiples espacios.

Texto preformateado

<pre>Hola       mundo
con   múltiples   espacios.</pre>

Saltos de línea y líneas horizontales

No uses varios <p> o <br> seguidos para “hacer espacio”. Para espaciado, usa CSS. El salto de línea <br> es útil dentro de direcciones, poemas o frases cortas.

Salto de línea

<p>Línea 1<br>Línea 2<br>Línea 3</p>

Línea horizontal

<p>Encabezado de sección</p>
<hr>
<p>Contenido de la sección</p>

Párrafos vs. elementos en línea

<p> es un elemento de bloque (ocupa todo el ancho). Elementos como <span>, <strong> o <em> son en línea y no inician un nuevo párrafo.

<p>Este es un <strong>párrafo</strong> con un <span>trozo en línea</span>.</p>

Buenas prácticas

  • Usa un párrafo por idea o bloque de contenido.
  • Para separar visualmente, aplica márgenes con CSS, no múltiples <br>.
  • Usa <pre> solo cuando necesites preservar espacios/saltos tal cual (código, poesía, ASCII art).
  • Evita anidar elementos de bloque dentro de <p> (por ejemplo, no coloques <div> o <h2> dentro de un <p>).

Mini cuestionario

2) ¿Cuándo usar <br>?
3) ¿Qué elemento mantiene espacios y saltos tal cual?
4) ¿Qué etiqueta dibuja una separación temática?
