Elementos HTML

¿Qué es un elemento?

Un elemento HTML suele estar formado por una etiqueta de apertura, el contenido y una etiqueta de cierre:

<p>Hola, mundo</p>
  • Apertura: <p>
  • Contenido: Hola, mundo
  • Cierre: </p>

Anidamiento de elementos

Los elementos pueden anidarse (colocarse dentro de otros). Mantén el orden: el último en abrir es el primero en cerrar.

<p>Texto con <strong>énfasis fuerte</strong> y <em>énfasis</em>.</p>

Elementos vacíos (void)

Algunos elementos no tienen contenido y, por lo tanto, no llevan etiqueta de cierre. Ejemplos comunes:

Línea 1<br>Línea 2

br – salto de línea

<img src="img/foto.jpg" alt="Descripción">

img – imagen con alt

<hr>

hr – regla horizontal

<meta charset="utf-8">
<link rel="stylesheet" href="style.css">
<input type="text">

meta, link, input – otros elementos vacíos

¿Cierre opcional?

Algunos elementos (p. ej., <li>, <p>) tienen cierre opcional según las reglas del parser HTML. Recomendación: ciérralos siempre para evitar errores de anidamiento y mantener el código claro.

<ul>
  <li>Uno</li>
  <li>Dos</li>
</ul>

Mayúsculas vs minúsculas

HTML no distingue mayúsculas/minúsculas en nombres de etiquetas y atributos; sin embargo, la convención moderna es escribirlos en minúsculas y con comillas para valores de atributos.

<P CLASS="destacado">Funciona, pero usa minúsculas</P>
<p class="destacado">Forma recomendada</p>

Comentarios

No son elementos, pero te ayudan a documentar:

<!-- Sección de artículos -->
<section>...</section>
