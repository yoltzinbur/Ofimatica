Listas HTML

Las listas organizan ítems con <li>. Hay tres tipos principales: no ordenadas (<ul>), ordenadas (<ol>) y de descripción (<dl>).

Lista no ordenada (ul)

<ul>
  <li>Manzana</li>
  <li>Naranja</li>
  <li>Plátano</li>
</ul>
  • Manzana
  • Naranja
  • Plátano

Lista ordenada (ol)

Admite estilos de numeración (type), inicio personalizado (start) e inversión (reversed).

Type / Start

<ol type="A" start="3">
  <li>Paso</li>
  <li>Paso</li>
</ol>
  1. Paso
  2. Paso

Reversed

<ol reversed>
  <li>Cuenta atrás</li>
  <li>Lanzamiento</li>
</ol>
  1. Cuenta atrás
  2. Lanzamiento

Listas anidadas

<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>

Lista de descripción (dl)

Útil para pares término–definición.

<dl>
  <dt>API</dt>
  <dd>Interfaz de programación de aplicaciones.</dd>
  <dt>DOM</dt>
  <dd>Modelo de objetos del documento.</dd>
</dl>
API
Interfaz de programación de aplicaciones.
DOM
Modelo de objetos del documento.

Personalizar viñetas con CSS

Tipos predefinidos

<ul class="list-square">...</ul>
<ol class="list-roman">...</ol>

Con ::marker

ul.custom-markers li::marker{content:"✔ ";font-weight:700}
  • Accesible
  • Rápido
  • Moderno

Quitar viñetas

<ul class="list-none">
  <li>Elemento sin viñeta</li>
</ul>
<style>
  .list-none{list-style:none;padding-left:0}
</style>

Accesibilidad

  • Usa listas solo para contenido que realmente sea una lista.
  • No insertes saltos de línea para simular listas; emplea ul/ol con li.
  • En listas de navegación, puedes retirar viñetas con CSS pero mantén la estructura semántica.
