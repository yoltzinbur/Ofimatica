HTML JavaScript

Inserta JavaScript en HTML con la etiqueta <script>. Puedes escribir el código inline o enlazar un archivo externo con src. Para rendimiento, considera defer o async y ubica los scripts adecuadamente.

Cargando…

Sintaxis básica

<script>
  document.getElementById("demo").textContent = "Hola desde JS";
</script>

—

Script externo con src

Reutiliza y organiza el código en archivos separados.

<!-- En el HTML -->
<script src="assets/app.js"></script>

Nota: si usas src, no mezcles código inline en la misma etiqueta.

defer y async

  • defer: descarga en paralelo y ejecuta tras parsear el HTML (en orden).
  • async: descarga y ejecuta en cuanto esté listo (no garantiza orden).
<script src="assets/app.js" defer></script>
<script src="assets/otro.js" async></script>

Ubicación: <head> vs <body>

En <head> usa defer para no bloquear el render. Alternativamente, coloca el script al final de <body> para que el DOM ya exista.

<!-- Opción A: en el head con defer -->
<script src="main.js" defer></script>

<!-- Opción B: justo antes de </body> -->
<script src="main.js"></script>

Soporte sin JavaScript: <noscript>

Muestra un mensaje alternativo si el navegador no ejecuta JavaScript.

<noscript>Activa JavaScript para ver esta página correctamente.</noscript>

Demo: evento y manipulación del DOM

<p id="msg">Mensaje inicial</p>
<button onclick="document.getElementById('msg').textContent='¡Actualizado por JS!'">Actualizar</button>
