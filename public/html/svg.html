HTML SVG

SVG (Scalable Vector Graphics) es un formato de gráficos vectoriales basado en XML que se integra directamente en documentos HTML. A diferencia de las imágenes rasterizadas, los gráficos SVG mantienen su calidad sin importar el nivel de zoom.

Ejemplo básico de SVG

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" 
          stroke="green" stroke-width="4" fill="yellow" />
</svg>

Círculo SVG básico

Ventajas de SVG

  • Escalabilidad infinita - Sin pérdida de calidad
  • Archivos pequeños - Ideal para web
  • Editabilidad - Se puede modificar con CSS y JavaScript
  • Accesibilidad - Soporte para texto alternativo
  • Animaciones - Compatible con CSS y SMIL
  • SEO friendly - Indexable por motores de búsqueda

SVG con estilos CSS

<svg width="200" height="100">
  <rect class="mi-rectangulo" 
        width="150" height="80" x="25" y="10" />
</svg>
<style>
.mi-rectangulo {
  fill: #E91E63;
  stroke: #C2185B;
  stroke-width: 3;
  rx: 10; /* Bordes redondeados */
}
</style>

Rectángulo con estilos CSS

SVG interactivo con JavaScript

<svg width="200" height="100">
  <circle id="circulo-interactivo" 
          cx="100" cy="50" r="30" 
          fill="#4CAF50" />
</svg>
<script>
document.getElementById('circulo-interactivo')
  .addEventListener('click', function() {
    this.style.fill = this.style.fill === '#4CAF50' ? '#FF5722' : '#4CAF50';
  });
</script>

Atributos principales de SVG

Atributo Descripción Ejemplo
fill Color de relleno fill="red"
stroke Color del borde stroke="blue"
stroke-width Grosor del borde stroke-width="2"
width/height Dimensiones del SVG width="200" height="100"
viewBox Sistema de coordenadas viewBox="0 0 100 100"

Ejemplo complejo: Icono de corazón

<svg width="100" height="100" viewBox="0 0 100 100">
  <path d="M50,85 C30,70 10,55 10,30 A20,20 0 0,1 50,30 A20,20 0 0,1 90,30 C90,55 70,70 50,85 Z"
        fill="#ff6b6b" stroke="#ee5a52" stroke-width="2"/>
</svg>
