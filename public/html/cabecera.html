Encabezado HTML (<head>)

El elemento <head> contiene metadatos y recursos de la página: título, metaetiquetas, hojas de estilo, scripts, favicon y más.

Ejemplo completo de <head>

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Título de la página</title>
  <meta name="description" content="Descripción concisa de la página">
  <meta name="author" content="Tu nombre o marca">
  <link rel="icon" href="assets/img/favicon.svg" type="image/svg+xml">
  <link rel="stylesheet" href="assets/style.css">
  <script defer src="assets/app.js"></script>
  <!-- <base href="/" target="_self">  (opcional y con cuidado) -->
</head>

<title>

Se muestra en la pestaña/ventana del navegador y es clave para accesibilidad y SEO.

<title>Guía de HTML: <head></title>

Metaetiquetas útiles

  • charset: codificación del documento (UTF-8).
  • viewport: diseño adaptable a móviles.
  • description: resumen claro (≈ 50–160 caracteres).
  • author, robots: información y rastreo.
<meta name="robots" content="index,follow">

Nota: la meta keywords ya no es usada por motores de búsqueda modernos.

Favicon y CSS

<link rel="icon" href="assets/img/favicon.svg" type="image/svg+xml">
<link rel="stylesheet" href="assets/style.css">

Scripts

Coloca JS en <head> con defer para no bloquear el renderizado.

<script defer src="assets/app.js"></script>

Estilos embebidos

Para pequeños ajustes locales puedes usar <style>.

<style>
  .btn-primary{padding:.6rem 1rem;border-radius:.6rem}
</style>

<base> (con cuidado)

Define la URL base para todas las rutas relativas.

<base href="/" target="_self">

Si la usas, verifica que todos tus enlaces/recursos sigan resolviendo correctamente.
