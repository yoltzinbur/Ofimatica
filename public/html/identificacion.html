Identificación HTML (id)

El atributo id asigna un identificador único a un elemento. Sirve para apuntarlo desde CSS, JavaScript o enlaces internos (marcadores).

Importante: el valor de id debe ser único dentro del documento.

Sintaxis básica

<h2 id="seccion-intro">Introducción</h2>
<p>Contenido de la introducción.</p>

Seleccionar con CSS (#)

Para seleccionar por id usa el hash # seguido del nombre.

#destacado{background:#f0f9ff;border:1px solid #bae6fd;padding:.6rem;border-radius:.6rem}
<p id="destacado">Bloque resaltado por id.</p>

Bloque resaltado por id.

Seleccionar con JavaScript

Usa document.getElementById('id') para obtener exactamente un elemento.

<button id="btn">Cambiar texto</button>
<p id="mensaje">Texto original</p>
<script>
document.getElementById("btn").addEventListener("click", () => {
  document.getElementById("mensaje").textContent = "Texto actualizado";
});
</script>

Enlaces internos (marcadores)

Un enlace puede “saltar” a un elemento con id usando href="#id".

<a href="#destino">Ir a la sección destino</a>
...
<h3 id="destino">Sección destino</h3>

Diferencia entre id y class

  • id: único en el documento. Selección precisa, anclajes, scripts.
  • class: reutilizable en múltiples elementos. Ideal para estilos repetibles.
  • Puedes combinar ambos: p. ej., id="hero" y class="seccion portada".

Buenas prácticas

  • Usa nombres descriptivos y estables (kebab-case): main-header, site-footer.
  • Evita reutilizar el mismo id en varios elementos.
  • No empieces con números ni uses espacios; los id distinguen mayúsculas/minúsculas.
  • Úsalo para objetivos específicos (marcadores, JS) más que para estilado masivo.
