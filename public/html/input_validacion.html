Validación de Entrada HTML

Aprende a validar formularios usando las características nativas de HTML5 y JavaScript

Introducción a la Validación de Entrada

La validación de entrada es crucial para garantizar que los datos ingresados por los usuarios sean correctos y seguros. HTML5 introdujo características de validación integradas que permiten validar datos sin necesidad de JavaScript.

En esta guía, exploraremos diferentes métodos de validación, desde la validación nativa de HTML5 hasta la validación personalizada con JavaScript.

Tipos de Validación HTML5

Validación de Tipo

Campos como email, url, y number validan automáticamente el formato.

Atributos de Restricción

required, min, max, pattern, etc.

Pseudoclases CSS

:valid, :invalid, :required para estilizar según el estado.

API de Validación

Métodos JavaScript como checkValidity() y setCustomValidity().

Atributos de Validación HTML5

Atributo Descripción Ejemplo
required El campo debe completarse antes de enviar el formulario <input required>
min / max Valores mínimo y máximo para campos numéricos <input type="number" min="1" max="100">
minlength / maxlength Longitud mínima y máxima para campos de texto <input minlength="3" maxlength="10">
pattern Expresión regular para validar el formato <input pattern="[A-Za-z]{3}">
type Tipo específico con validación incorporada <input type="email">
step Intervalos legales para campos numéricos <input type="number" step="5">

Validación con JavaScript

Validación Personalizada

// Validación personalizada con JavaScript
function validateForm() {
  const username = document.getElementById('custom-username').value;
  const password = document.getElementById('custom-password').value;
  const confirmPassword = document.getElementById('custom-password-confirm').value;

  // Validar nombre de usuario
  if (username.length < 3) {
    showError('custom-username', 'El nombre debe tener al menos 3 caracteres');
    return false;
  }

  // Validar que las contraseñas coincidan
  if (password !== confirmPassword) {
    showError('custom-password-confirm', 'Las contraseñas no coinciden');
    return false;
  }

  return true;
}
