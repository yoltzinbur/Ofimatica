Clases HTML (class)

El atributo class permite asignar un nombre (o varios) a un elemento para aplicarle estilos con CSS o seleccionarlo con JavaScript. Varios elementos pueden compartir la misma clase.

Sintaxis básica

<p class="nota">Texto con estilo de la clase <em>nota</em>.</p>
<style>
.nota{background:#fff7ed;border:1px solid #fed7aa;padding:.5rem;border-radius:.5rem}
</style>

Ejemplo con class="nota"

Múltiples clases

Puedes separar clases por espacios para combinar estilos.

<div class="tarjeta destacado">
  Contenido importante
</div>
Contenido importante

Seleccionar por clase en CSS

Usa el punto (.) antes del nombre: .tarjeta { ... }.

.tarjeta{border:1px solid #e5e7eb;border-radius:.6rem;padding:.6rem}
.tarjeta .tag{margin-right:.25rem}
.tarjeta.tag

Estilizadas por clase.

Seleccionar por clase en JavaScript

Dos formas comunes:

  • document.getElementsByClassName('clase') — HTMLCollection vivo.
  • document.querySelectorAll('.clase') — NodeList estático (permite selectores complejos).
<ul>
  <li class="item">A</li>
  <li class="item">B</li>
</ul>
<script>
const items = document.getElementsByClassName("item");
for(const el of items){ el.style.fontWeight = "bold"; }
</script>

Buenas prácticas

  • Usa nombres descriptivos y en minúsculas/kebab-case: .product-card, .btn-primary.
  • Reutiliza clases para estilos consistentes en varios elementos.
  • Evita nombres demasiado genéricos como .red si el significado es semántico (mejor .error).
  • Combina múltiples clases para variaciones: class="btn btn--primary".
