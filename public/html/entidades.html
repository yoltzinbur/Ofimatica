Entidades HTML

Las entidades HTML permiten escribir caracteres que el parser interpreta como código o que no están en el teclado, usando nombres (&nbsp;) o códigos numéricos (&#160; o &#x00A0;).

¿Cuándo usar entidades?

  • Para mostrar caracteres reservados: <, >, &, ", '.
  • Para espacios especiales y tipografía: &nbsp; (espacio duro), &shy; (guion suave).
  • Para símbolos, letras griegas, flechas, etc. (ver Símbolos HTML).
Codificación: Usa <meta charset="utf-8">. Con UTF-8 puedes escribir la mayoría de caracteres directamente; las entidades siguen siendo útiles para los reservados y ciertos espacios/controles.

Caracteres reservados comunes

&lt;div class="caja">Tom &amp; Jerry</div>

Se renderiza como:

<div class="caja">Tom & Jerry</div>

Con nombre vs numéricas

Las entidades pueden escribirse con nombre (&copy;) o con número decimal/hex (&#169; / &#x00A9;).

&copy; 2025 · &#169; 2025 · &#x00A9; 2025
© 2025 · © 2025 · © 2025

Espacios y guiones especiales

Espacio duro: &nbsp;

Evita que dos palabras se separen al final de línea.

Precio:&nbsp;$199
Precio: $199

Guion suave: &shy;

Inserta un posible punto de corte (solo se muestra si hay salto).

extraor&shy;dinariamente
extraor­dinariamente

Buenas prácticas

  • Escribe directamente con UTF-8 cuando sea posible, pero usa entidades para caracteres reservados y espacios/tipos especiales.
  • Para máxima compatibilidad, los símbolos pueden escribirse como códigos numéricos (&#...; o &#x...;).
  • En atributos HTML, usa &quot; o comillas simples alrededor del valor y escapa & y < si aparecen.
