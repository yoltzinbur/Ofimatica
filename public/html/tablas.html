Tablas HTML

Una <table> organiza datos en filas (<tr>) y celdas de encabezado <th> o datos <td>. Usa <thead>, <tbody> y <tfoot> para estructura, y el atributo scope en <th> para accesibilidad.

Tabla básica

<table>
  <tr><th>Nombre</th><th>Edad</th></tr>
  <tr><td>Ana</td><td>28</td></tr>
  <tr><td>Luis</td><td>31</td></tr>
</table>
NombreEdad
Ana28
Luis31

Secciones: thead / tbody / tfoot

<table>
  <thead><tr><th scope="col">Producto</th><th scope="col">Precio</th></tr></thead>
  <tbody>
    <tr><td>Libro</td><td>12.00</td></tr>
    <tr><td>Cuaderno</td><td>3.50</td></tr>
  </tbody>
  <tfoot><tr><th scope="row" colspan="2">Precios en USD</th></tr></tfoot>
</table>

Bordes, colapsado y padding

Bordes sencillos

<table class="bordered">...</table>
<style>
  table.bordered{border-collapse:collapse}
  table.bordered th,table.bordered td{border:1px solid #ddd;padding:.5rem}
</style>

Colapsar bordes

Usa border-collapse:collapse para evitar bordes dobles.

Espaciado interno

Controla con padding en th/td.

Caption (título de la tabla)

<table>
  <caption>Ventas trimestrales</caption>
  <tr><th>Q1</th><th>Q2</th><th>Q3</th><th>Q4</th></tr>
  <tr><td>12</td><td>15</td><td>9</td><td>20</td></tr>
</table>
Ventas trimestrales
Q1Q2Q3Q4
1215920

Combinar celdas: colspan y rowspan

<table>
  <tr><th>Nombre</th><th colspan="2">Contacto</th></tr>
  <tr><td rowspan="2">Ana</td><td>Email</td><td>ana@ej.com</td></tr>
  <tr><td>Tel.</td><td>555-123</td></tr>
</table>

Filas “cebra” (zebra stripes)

Alterna el fondo de filas con CSS para legibilidad.

table.zebra tbody tr:nth-child(odd){background:#f7f7f7}

Tabla responsiva (scroll horizontal)

Cuando hay muchas columnas, envuelve la tabla en un contenedor con overflow-x:auto.

<div style="overflow-x:auto">
  <table>...</table>
</div>
#ABC DEFG
1αβγδεζη
2θικλμνξ

Accesibilidad

  • Usa <th> para encabezados y añade scope="col" / scope="row".
  • Para tablas complejas, considera id en <th> y el atributo headers en <td>.
  • Incluye <caption> descriptivo.
