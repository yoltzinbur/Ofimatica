Diseño HTML

HTML ofrece elementos semánticos para estructurar una página y CSS para posicionarlos. Abajo tienes el mapa de elementos y ejemplos con Flexbox y Grid.

Elementos de diseño (semánticos)

  • <header> – Encabezado del sitio o sección.
  • <nav> – Conjunto de enlaces de navegación.
  • <section> – Sección temática del documento.
  • <article> – Contenido independiente/autónomo.
  • <aside> – Contenido complementario (barra lateral).
  • <footer> – Pie de página del sitio o sección.
  • <details> / <summary> – Bloques con contenido desplegable.

Esqueleto básico de layout

<header>Encabezado</header>
<nav>... enlaces ...</nav>
<main>
  <section>Sección principal</section>
  <aside>Barra lateral</aside>
</main>
<footer>Pie</footer>

Layout con Flexbox (rápido)

Ideal para barras de navegación o columnas simples.

<style>
.nav{display:flex;gap:1rem;flex-wrap:wrap}
.main{display:flex;gap:1rem}
.main > section{flex:1}
.main > aside{width:280px}
@media (max-width:800px){.main{flex-direction:column}.main > aside{width:auto}}
</style>

<nav class="nav"><a href="#">Inicio</a><a href="#">Blog</a><a href="#">Contacto</a></nav>
<div class="main">
  <section>Contenido...</section>
  <aside>Sidebar...</aside>
</div>

Layout con CSS Grid (potente)

Perfecto para maquetaciones de página completas.

<style>
.wrapper{
  display:grid;gap:10px;
  grid-template-areas:
    'header' 'nav' 'content' 'aside' 'footer';
}
header{grid-area:header}
nav{grid-area:nav}
main{grid-area:content}
aside{grid-area:aside}
footer{grid-area:footer}
@media (min-width:900px){
  .wrapper{
    grid-template-columns:200px 1fr 260px;
    grid-template-areas:
      'header header header'
      'nav content aside'
      'footer footer footer';
  }
}
</style>

<div class="wrapper">
  <header>Encabezado</header>
  <nav>Menú</nav>
  <main>Contenido principal</main>
  <aside>Lateral</aside>
  <footer>Pie</footer>
</div>
