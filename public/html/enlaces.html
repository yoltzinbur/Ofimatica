Enlaces HTML

Los enlaces se crean con <a> y el atributo href indicando el destino.

Sintaxis básica

<a href="https://www.ejemplo.com">Ir al sitio</a>

Rutas absolutas vs relativas

Absoluta (URL completa)

<a href="https://www.w3schools.com/html/">W3Schools HTML</a>

Relativa (dentro del sitio)

<a href="imagenes.html">Ir a imágenes</a>

Abrir en nueva pestaña

Usa target="_blank". Por seguridad/rendimiento añade rel="noopener noreferrer".

<a href="https://developer.mozilla.org/" target="_blank" rel="noopener noreferrer">MDN en nueva pestaña</a>

Anclas internas (saltos en la misma página)

Crea un destino con id y enlázalo con #id.

<a href="#contacto">Ir a Contacto</a>
...
<h2 id="contacto">Contacto</h2>

mailto:, tel: y otros esquemas

Correo

<a href="mailto:soporte@ejemplo.com?subject=Consulta">Escríbenos</a>

Teléfono

<a href="tel:+5215512345678">Llamar</a>

Imagen como enlace

Envuelve la imagen con <a>. No olvides el alt en la imagen.

<a href="index.html">
  <img src="assets/img/logo-mini.png" alt="Ir al inicio" width="120">
</a>

Descargar un archivo

El atributo download sugiere descargar el recurso en lugar de abrirlo en el navegador.

<a href="assets/guia.pdf" download>Descargar guía (PDF)</a>
