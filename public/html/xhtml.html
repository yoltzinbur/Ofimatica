HTML vs XHTML

XHTML (eXtensible HyperText Markup Language) es HTML expresado con las reglas estrictas de XML. Eso implica documentos bien formados, todas las etiquetas cerradas, atributos siempre entre comillas, nombres en minúsculas y anidamiento correcto.

Principales diferencias

AspectoHTMLXHTML
SintaxisTolerante (los navegadores corrigen errores)Debe ser XML bien formado
Mayúsculas/minúsculasNo estrictominúsculas para nombres de elementos/atributos
Cierre de etiquetasAlgunas opcionalesTodas deben cerrarse
AtributosValores sin comillas a veces válidosValores siempre con comillas
Vacíos (void)<br>, <img>…Se permiten como <br />, <img /> (autocierre XML)
EntidadesComo en HTMLUsa entidades válidas en XML; & debe ser &amp;
DoctypeHTML5: <!doctype html>XHTML 1.0/1.1: Doctypes específicos
MIME typetext/htmlIdealmente application/xhtml+xml

Reglas de sintaxis en XHTML

  • Todos los elementos deben cerrarse (<p>...</p>).
  • Los elementos vacíos usan autocierre (<br />, <>img />).
  • Nombres de elementos y atributos en minúsculas.
  • Todos los valores de atributos con comillas (class="box").
  • Anidamiento correcto (no cruces etiquetas).
  • Los atributos booleanos requieren valor (checked="checked" en lugar de solo checked).

Ejemplo incorrecto (no XHTML)

<!doctype html>
<html>
<head>
<title>Demo</title>
</head>
<body>
  <img src="logo.png">
  <input type=checkbox checked>
  <p><b>Hola</p></b>
</body>
</html>

Correcto en XHTML 1.0

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
  "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml" lang="es" xml:lang="es">
<head>
  <title>Demo</title>
  <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
</head>
<body>
  <img src="logo.png" alt="Logo" />
  <input type="checkbox" checked="checked" />
  <p><strong>Hola</strong></p>
</body>
</html>

Doctypes comunes

<!-- XHTML 1.0 Strict -->
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
 "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

<!-- XHTML 1.0 Transitional -->
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
 "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

<!-- XHTML 1.1 -->
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN"
 "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd">

Entrega (MIME type) y compatibilidad

  • Para ser tratado realmente como XML, sirva el documento como application/xhtml+xml.
  • Si lo sirve como text/html, la mayoría de navegadores lo procesan como HTML y permiten ciertos errores.
  • Históricamente, algunos navegadores antiguos no manejaban bien application/xhtml+xml. Hoy es ampliamente soportado, pero HTML5 (no-XML) es estándar dominante.

Nota: En HTML5 no es necesario el autocierre XML (<br> es válido). Solo use / si realmente entrega como XHTML.

Pequeño ejercicio de conversión

Convierte este fragmento HTML a XHTML bien formado:

<!-- HTML suelto -->
<div id=wrap>
  <img src="foto.jpg">
  <a href="contacto.html" title=Contacto>Contacto</a>
</div>
Una solución posible 
<!-- XHTML -->
<div id="wrap">
  <img src="foto.jpg" alt="Foto" />
  <a href="contacto.html" title="Contacto">Contacto</a>
</div>
