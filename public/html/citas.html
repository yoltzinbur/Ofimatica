Citas HTML

HTML incluye elementos para representar citas y referencias con significado semántico: <blockquote>, <q>, <cite>, <abbr>, <address> y control de dirección de texto con <bdo>/<bdi>.

Bloques de cita: <blockquote>

Para citas largas en bloque. Puedes indicar la fuente con el atributo cite (URL).

<blockquote cite="https://www.ejemplo.com/articulo">
  La simplicidad es la máxima sofisticación.
</blockquote>
Consejo: el atributo cite no se muestra; sirve como metadato para agentes de usuario.
«La simplicidad es la máxima sofisticación.»

Citas en línea: <q>

Para citas cortas dentro del texto. El navegador suele añadir comillas automáticamente. También acepta cite.

<p>Como dijo Ada Lovelace: <q cite="https://www.britannica.com/biography/Ada-Lovelace">El motor puede componer música</q>.</p>

Como dijo Ada Lovelace: El motor puede componer música.

Referencia de obras: <cite>

Identifica el título de una obra (libro, artículo, película…). No es para personas.

<p>Leí <cite>El nombre de la rosa</cite> el verano pasado.</p>

Leí El nombre de la rosa el verano pasado.

Abreviaturas: <abbr>

Define abreviaturas y siglas. Usa el atributo title con la expansión.

<p><abbr title="Cascading Style Sheets">CSS</abbr> da estilo a las páginas.</p>

CSS da estilo a las páginas.

Información de contacto: <address>

Para datos de autor o contacto del documento o sección (no para direcciones postales genéricas sin relación).

<address>
  Escrito por <a href="mailto:ana@example.com">Ana</a><br>
  Madrid, España
</address>
Escrito por Ana
Madrid, España

Dirección de texto: <bdo> y <bdi>

<bdo dir="rtl|ltr"> anula la dirección del texto; <bdi> aísla fragmentos cuyo sentido de escritura puede variar.

Texto normal | <bdo dir="rtl">Texto invertido</bdo>

Texto normal | Texto invertido

Buenas prácticas

  • Usa <blockquote> para citas extensas y <q> para citas cortas en línea.
  • Indica la fuente con cite cuando sea posible.
  • No uses <cite> para personas; es para títulos de obras.
  • Siempre incluye title en <abbr> para accesibilidad.

Mini cuestionario

1) ¿Qué elemento usas para una cita larga con posible URL de fuente?
2) ¿Para qué sirve el atributo title en <abbr>?
3) ¿Cuál marca el título de una obra?
4) ¿Qué hace <bdo dir="rtl">?
