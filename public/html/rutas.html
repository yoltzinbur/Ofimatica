Rutas de archivos HTML

Una ruta de archivo indica dónde está un recurso (imágenes, CSS, JS, páginas) respecto al documento actual o al sitio.

Estructura de ejemplo del proyecto

/ (raíz del sitio)
├─ index.html
├─ rutas.html   ← (página actual)
├─ assets/
│  ├─ style.css
│  ├─ app.js
│  └─ img/
│     ├─ logo.png
│     ├─ fotos/
│     │  └─ playa.jpg
│     └─ ui/
│        └─ icon-info.svg
└─ pages/
   └─ acerca.html

Relativa al documento (misma carpeta)

Cuando el recurso está en la misma carpeta que el HTML.

<a href="index.html">Volver al inicio</a>

Subcarpetas

Cuando el recurso está por debajo del documento actual.

<img src="assets/img/logo.png" alt="Logo" width="120" height="120">

Sub-subcarpetas

Profundizando más niveles.

<img src="assets/img/fotos/playa.jpg" alt="Playa" width="320" height="200">

Volver al nivel superior: ../

../ sube un nivel desde la carpeta actual. Útil cuando tu HTML está dentro de carpetas.

<!-- Desde pages/acerca.html -->
<link rel="stylesheet" href="../assets/style.css">

Directorio actual: ./

./ apunta al directorio actual. Es opcional, pero hace explícita la intención.

<a href="./rutas.html">Esta página</a>

Ruta relativa a la raíz del sitio

Empieza con / (requiere servidor que tenga claro el “document root”).

<!-- Desde cualquier lugar del sitio -->
<link rel="icon" href="/assets/img/ui/icon-info.svg" type="image/svg+xml">

En entornos estáticos (abrir archivos con file://) estas rutas pueden no resolver como esperas. Para pruebas locales usa un servidor simple (por ejemplo npx serve o la extensión “Live Server”).

Rutas absolutas (URL completas)

Incluyen protocolo y dominio. Úsalas para recursos externos. Para recursos internos, prefiere rutas relativas o relativas a la raíz.

<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

Buenas prácticas

  • Usa rutas cortas y coherentes con la estructura de carpetas.
  • Para recursos del sitio, prefiere relativas o relativas a la raíz.
  • Evita ..\ (barra invertida de Windows) en HTML: usa /.
  • Verifica mayúsculas/minúsculas: en servidores Linux, Logo.png ≠ logo.png.
  • Si mueves archivos, actualiza las rutas o considera una estructura más estable.

Ejemplo CSS y JS

<link rel="stylesheet" href="assets/style.css">
<script src="assets/app.js" defer></script>

Imágenes en subcarpetas

<img src="assets/img/ui/icon-info.svg" alt="Info" width="24" height="24">
