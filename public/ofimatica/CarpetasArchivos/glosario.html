Glosario de términos 📚

Cómo usar este glosario

Aquí tienes los conceptos más importantes relacionados con archivos, carpetas, organización y respaldo. La idea es que puedas volver rápido a esta página cuando un término te suene pero no lo tengas tan claro.

Recomendación: marca esta página como favorita en tu navegador si la usarás como referencia para tareas o trabajos.

📄

Archivo

Unidad de información guardada en el equipo. Tiene un nombre y una extensión (por ejemplo: informe.pdf, foto.jpg).

📁

Carpeta

Contenedor donde se guardan archivos y otras carpetas (subcarpetas). Sirve para organizar la información por temas, proyectos o materias.

🧭

Ruta

Dirección que indica dónde está un archivo o carpeta dentro del sistema. Ejemplo: C:\Usuarios\Melani\Documentos.

🏷️

Extensión

Parte del nombre del archivo que va después del punto y que indica su tipo (.pdf, .jpg, .mp3, .zip, etc.).

📂

Directorio

Otro nombre para “carpeta”. A veces también se habla de directorio raíz, que es la carpeta base principal de una unidad (por ejemplo C:\).

🧱

Subcarpeta

Carpeta que está dentro de otra carpeta. Ayuda a crear una estructura jerárquica más ordenada.

🪟

Explorador de archivos

Programa del sistema operativo que permite ver, abrir, copiar, mover, renombrar y borrar archivos y carpetas (en Windows se llama Explorador de archivos).

📋

Portapapeles

Zona de memoria temporal donde se guarda lo que copias o cortas (por ejemplo con Ctrl+C o Ctrl+X) hasta que lo pegas.

📦

Comprimir

Acción de reducir el tamaño de uno o varios archivos y agruparlos en un solo archivo comprimido, por ejemplo .zip o .rar.

📤

Descomprimir

Proceso inverso: extraer el contenido de un archivo comprimido (.zip, .rar, .7z) para volver a tener las carpetas y archivos originales.

☁️

Copia de seguridad (backup)

Duplicado de tus archivos importante guardado en otro lugar (nube, disco externo…) para poder recuperarlos si algo falla.

🔄

Sincronización

Proceso que mantiene iguales dos ubicaciones (por ejemplo, carpeta del PC y carpeta en la nube) actualizando los cambios automáticamente.

👤

Usuario

Cuenta con la que inicias sesión en un equipo o servicio. Cada usuario puede tener sus propias carpetas, permisos y ajustes.

🔐

Permisos

Reglas que indican quién puede leer, modificar o eliminar un archivo o carpeta. Son muy importantes en carpetas compartidas.

⛓️

Acceso directo / acceso rápido

Icono o enlace que apunta a un archivo o carpeta original. No es una copia: si borras el archivo original, el acceso directo deja de funcionar.

⚙️

Ejecutable

Archivo que contiene instrucciones que el sistema puede ejecutar. Por ejemplo: .exe, .bat, .sh. Se usan para instalar programas o automatizar tareas.

⌨️

Atajo de teclado

Combinación de teclas que hace una acción rápida (por ejemplo Ctrl+C para copiar, Ctrl+Z para deshacer).

🗑️

Papelera de reciclaje

Carpeta especial donde van los archivos eliminados antes de borrarse definitivamente. Permite recuperar archivos borrados por error.

📌

Versión

Número o etiqueta que indica una “etapa” de un mismo archivo: v01, v02, final, etc. Ayuda a saber cuál es el archivo más reciente o aprobado.

📑

Metadatos

Datos sobre el archivo: autor, fecha de creación, fecha de modificación, tamaño, etiquetas, permisos, etc. No son el contenido, sino información adicional sobre él.

🧮

Sistema de archivos

Forma en que un sistema operativo organiza y administra los archivos en un disco o memoria. Ejemplos: NTFS, FAT32, exFAT.

Tip para estudiar con este glosario

Si estás usando este manual para una materia o curso, puedes:

  • Repasar el glosario antes de hacer el quiz.
  • Subrayar los términos que más se usan en tus tareas.
  • Crear tus propias tarjetas de estudio (flashcards) con definición por atrás.

Cuanto más uses estos términos en voz alta o en tus apuntes, más naturales se volverán para ti.
