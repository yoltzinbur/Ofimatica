Operaciones comunes ⚙️

✨

Crear archivos y carpetas

En el Explorador de archivos, haz clic derecho en un espacio vacío → Nuevo → elige Carpeta o el tipo de archivo que necesites (documento de texto, presentación, hoja de cálculo, etc.).

Es mejor crear los archivos dentro de la carpeta de tu proyecto y no dejarlos tirados en el Escritorio o en Descargas. Así, desde el inicio, todo queda en su lugar.

Ejemplo de nombre 2025-10-23_proyecto-v01 (fecha + tema + versión).

✅ Carpetas sirven para agrupar cosas (proyectos, materias, clientes). ✅ Archivos son los documentos concretos (informes, imágenes, audios, etc.).

✏️

Renombrar

Para cambiar el nombre de un archivo o carpeta:

  • Windows selecciona el archivo y pulsa F2.
  • macOS selecciona el archivo y pulsa Enter.
  • También puedes usar clic derecho → Cambiar nombre.

Evita caracteres raros como / \ ? * : y los nombres poco claros como "nuevo", "cosas", "varios".

👍 Un buen formato puede ser: AAAA-MM-DD_tema_v01 Ej.: 2025-03-12_acta-reunion_v02.pdf. Así, al ordenar por nombre o fecha, verás las versiones en orden.

📄

Copiar / Pegar

Sirve para duplicar archivos sin mover el original.

  • Windows Ctrl + C → Ctrl + V.
  • macOS ⌘C → ⌘V.
  • También puedes usar el menú contextual: clic derecho → Copiar / Pegar.

Úsalo cuando quieras la misma información en dos carpetas distintas (por ejemplo: una copia para respaldo o para enviar a otra persona).

👉 Puedes copiar entre distintas unidades (disco interno, USB, disco externo). Solo recuerda expulsar el USB de forma segura antes de quitarlo para no dañar los datos.

📤

Mover (Cortar / Pegar)

Cambia un archivo de ubicación sin dejar copia en el lugar original.

  • Windows Ctrl + X → ve a la carpeta destino → Ctrl + V.
  • macOS ⌘C → en la carpeta destino, ⌥⌘V (pegar y mover).
  • También puedes arrastrar el archivo a otra carpeta.

Ideal para reorganizar proyectos o limpiar el escritorio, moviendo todo a su carpeta correcta.

⚠️ Solo mueve documentos, fotos, videos, etc. No es buena idea mover a mano las carpetas donde están instalados los programas, porque pueden dejar de funcionar.

🗑️

Eliminar

Quita archivos que ya no necesitas. Normalmente se mandan primero a la Papelera de reciclaje.

  • Windows Selecciona y pulsa Supr o clic derecho → Eliminar.
  • macOS ⌘ + ⌫ (borrar) o arrastra a la Papelera.

Vaciar la papelera elimina los archivos de forma más definitiva. Revisa antes de hacerlo.

⚠️ En Windows existe Shift + Supr (Eliminar sin pasar por la Papelera). No se recomienda para principiantes, porque recuperar esos archivos es mucho más difícil.

📦

Comprimir en .zip

Agrupa varios archivos en uno solo y reduce su tamaño para compartirlos o guardarlos.

  • Selecciona los archivos → clic derecho → Enviar a > Carpeta comprimida (.zip) (Windows).
  • En macOS: clic derecho → Comprimir.

Ideal para enviar proyectos completos o empaquetar documentos de forma ordenada.

💡 Antes de comprimir, asegúrate de que tu carpeta esté bien organizada por subcarpetas. Evita comprimir cosas que ya están muy comprimidas (.mp4, .jpg): apenas se reducirá el tamaño.
