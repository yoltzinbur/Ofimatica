Atajos de teclado ⌨️

¿Por qué usar atajos?

Los atajos de teclado te permiten copiar, mover, renombrar y buscar archivos sin depender solo del ratón. Ahorran tiempo, reducen errores y hacen que trabajar con carpetas sea mucho más ágil.

Truco Aprende primero 3 o 4 atajos básicos y repítelos todos los días. Cuando los uses sin pensar, pasa a los siguientes.

Atajos básicos para archivos y carpetas

Copiar

Ctrl + C / ⌘ + C

Duplica el archivo o carpeta seleccionada sin mover el original.

Cortar (mover)

Ctrl + X / ⌘ + X

Prepara el archivo para cambiarlo de ubicación.

Pegar

Ctrl + V / ⌘ + V

Pega lo que copiaste o cortaste en la carpeta actual.

Renombrar

F2 (Windows) / Enter sobre el nombre (macOS)

Permite escribir un nuevo nombre sin usar el ratón.

Seleccionar todo

Ctrl + A / ⌘ + A

Selecciona todos los archivos de la carpeta actual.

Eliminar

Supr / ⌘ + Supr

Manda a la Papelera. Revisa antes de vaciarla.

Atajos del explorador de archivos

Nueva carpeta

Ctrl + Shift + N (Win / macOS)

Crea una carpeta en la ubicación actual.

Abrir explorador

Win + E / ⌘ + N (en Finder)

Abre una ventana nueva para gestionar archivos.

Deshacer acción

Ctrl + Z / ⌘ + Z

Sirve para recuperar algo que moviste o borraste por error.

Buscar archivo

Ctrl + F / ⌘ + F

Abre el cuadro de búsqueda dentro de la ventana actual.

Cerrar ventana

Alt + F4 / ⌘ + W

Cierra solo la ventana del explorador o Finder.

Cambiar entre ventanas

Alt + Tab / ⌘ + Tab

Útil para arrastrar archivos de una ventana a otra.

Resumen rápido (Windows / macOS)

Esta tabla resume los atajos más usados al trabajar con archivos y carpetas:

Acción Windows macOS Uso típico
Copiar Ctrl + C ⌘ + C Duplicar archivos o carpetas.
Cortar / mover Ctrl + X ⌘ + X Mover elementos a otra carpeta.
Pegar Ctrl + V ⌘ + V Completar la copia o movimiento.
Seleccionar todo Ctrl + A ⌘ + A Trabajar con muchos archivos a la vez.
Buscar Ctrl + F ⌘ + F Encontrar archivos o texto rápidamente.
Nueva carpeta Ctrl + Shift + N ⌘ + Shift + N Crear estructuras de carpetas ordenadas.

Cómo practicar los atajos

No intentes memorizar todos de golpe. Empieza con: Copiar, Cortar, Pegar, Renombrar y Seleccionar todo.

Durante una semana, intenta usar el teclado en lugar del ratón cada vez que copies o muevas un archivo. En poco tiempo, los atajos se volverán automáticos.
