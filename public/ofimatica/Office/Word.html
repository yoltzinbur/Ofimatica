Domina Microsoft Word 2025 con esta guía detallada: desde lo básico hasta funciones avanzadas, diseño profesional, colaboración en la nube, automatización y más. Incluye ejemplos prácticos, imágenes, consejos y tutoriales paso a paso.

Módulo 1. Introducción a Microsoft Word

Microsoft Word es el procesador de texto más utilizado en el mundo, ideal para crear documentos profesionales, académicos y personales. En este módulo, explorarás su interfaz, historia, versiones y cómo comenzar a trabajar con documentos.

¿Qué es Microsoft Word y para qué sirve?

Microsoft Word es una aplicación de procesamiento de texto que permite:

Creación de documentos

Desde cartas y currículums hasta informes técnicos y tesis académicas, con herramientas de formato avanzado.

Edición colaborativa

Trabaja en tiempo real con otros usuarios, con seguimiento de cambios y comentarios integrados.

Diseño profesional

Plantillas prediseñadas, estilos, temas y herramientas de diseño para documentos visualmente atractivos.

Automatización

Macros, campos dinámicos y combinación de correspondencia para ahorrar tiempo en tareas repetitivas.

Integración con la nube

Guarda y comparte documentos en OneDrive o SharePoint, con acceso desde cualquier dispositivo.

Herramientas de revisión

Corrector ortográfico, gramatical, diccionario de sinónimos y traductor integrado para documentos impecables.

Historia y evolución de Microsoft Word

Desde su lanzamiento en 1983, Word ha evolucionado para adaptarse a las necesidades de los usuarios, incorporando nuevas funciones y tecnologías:

1983

Word 1.0 para MS-DOS: Primera versión con interfaz de línea de comandos, limitada a texto plano y formato básico.

1989

Word para Windows: Interfaz gráfica con menús desplegables, barras de herramientas y soporte para fuentes TrueType.

1997

Word 97: Introducción del Asistente de Office (Clippy) y mejoras en la edición de tablas y gráficos.

2007

Word 2007: Revolucionaria interfaz con la cinta de opciones (Ribbon), reemplazando los menús tradicionales.

2016

Word 2016: Integración con OneDrive para colaboración en tiempo real y nuevas herramientas de diseño.

2025

Word 2025: Inteligencia artificial integrada (Copilot), diseño mejorado, automatización avanzada y mayor enfoque en la colaboración en la nube.

Dato curioso: El nombre "Word" fue elegido porque el equipo de desarrollo quería transmitir la idea de "procesamiento de palabras" de manera simple y directa.

Interfaz y entorno de trabajo en Word 2025

La interfaz de Word 2025 está diseñada para ser intuitiva y eficiente, con las siguientes áreas principales:

  • Barra de título: Muestra el nombre del documento y los botones para minimizar, maximizar y cerrar.
  • Cinta de opciones (Ribbon): Organizada en pestañas como Inicio, Insertar, Diseño, Referencias, etc.
  • Barra de herramientas de acceso rápido: Atajos a funciones como Guardar, Deshacer y Rehacer. Personalizable.
  • Regla: Guía visual para ajustar márgenes, sangrías y tabulaciones.
  • Área de trabajo: Espacio principal para editar el documento.
  • Barra de estado: Información como número de páginas, palabras, idioma y estado de guardado.
Consejo: Personaliza la barra de herramientas de acceso rápido añadiendo comandos que uses frecuentemente, como "Guardar como PDF" o "Imprimir".

Cómo crear, abrir, guardar y cerrar documentos

Operaciones básicas con documentos en Word 2025:

Crear un nuevo documento
  • Usa el atajo Ctrl + N.
  • O haz clic en Archivo → Nuevo y elige una plantilla.
  • Word ofrece plantillas para cartas, informes, currículums, folletos y más.
Abrir un documento existente
  • Usa el atajo Ctrl + O.
  • O haz clic en Archivo → Abrir y selecciona el archivo desde OneDrive o tu equipo.
  • Word muestra los documentos recientes para acceso rápido.
Guardar un documento
  • Usa el atajo Ctrl + S para guardar cambios.
  • Para guardar como un nuevo archivo, usa F12 o Archivo → Guardar como.
  • Elige entre formatos como .docx (predeterminado), .pdf, .txt o .odt.
Cerrar un documento
  • Usa el atajo Ctrl + W.
  • O haz clic en la X de la pestaña del documento.
  • Word pregunta si deseas guardar cambios antes de cerrar.
Importante: Configura el AutoGuardado en OneDrive para evitar perder cambios por errores o cierres inesperados. Ve a Archivo → Opciones → Guardar y activa la opción.

Módulo 2. Trabajo con Texto

Aprende a manejar texto de manera eficiente: escribir, editar, seleccionar, copiar, pegar, buscar, reemplazar e insertar caracteres especiales. Este módulo cubre todo lo que necesitas para trabajar con texto en Word 2025.

Escribir, editar y eliminar texto

Las operaciones básicas con texto son fundamentales para cualquier documento:

Escribir texto
  • Simplementa haz clic en el documento y comienza a teclear.
  • Word ajusta automáticamente el flujo del texto a medida que escribes.
  • Usa Enter para nuevos párrafos y Shift + Enter para saltos de línea.
Editar texto
  • Haz clic en el texto que deseas modificar y realiza los cambios.
  • Usa las teclas de flecha para mover el cursor.
  • Para seleccionar texto, mantén presionado Shift mientras mueves el cursor.
Eliminar texto
  • Selecciona el texto y presiona Supr o Retroceso.
  • Para eliminar una palabra completa, usa Ctrl + Retroceso (antes del cursor) o Ctrl + Supr (después del cursor).
Seleccionar todo el texto
  • Usa el atajo Ctrl + E para seleccionar todo el texto del documento.
  • O presiona Ctrl + A para seleccionar todo, incluyendo imágenes y otros elementos.

Seleccionar, copiar, cortar y pegar texto

Estas operaciones son esenciales para mover y duplicar texto dentro de un documento o entre documentos:

Seleccionar texto
  • Arrastra el cursor sobre el texto para seleccionarlo.
  • Usa Shift + Flechas para seleccionar carácter por carácter.
  • Para seleccionar una palabra, haz doble clic sobre ella.
  • Para seleccionar un párrafo, haz triple clic.
Copiar y pegar texto
  • Copiar: Selecciona el texto y presiona Ctrl + C.
  • Pegar: Coloca el cursor en la nueva ubicación y presiona Ctrl + V.
  • Usa Ctrl + Shift + V para pegar sin formato.
Cortar y pegar texto
  • Cortar: Selecciona el texto y presiona Ctrl + X.
  • Pegar: Coloca el cursor en la nueva ubicación y presiona Ctrl + V.
Portapapeles de Office
  • Word guarda hasta 24 elementos en el portapapeles.
  • Accede al historial del portapapeles haciendo clic en el icono del portapapeles en la pestaña Inicio.
  • Pega cualquier elemento del historial haciendo clic en él.

Buscar y reemplazar palabras o frases

Estas herramientas son útiles para localizar y modificar texto en documentos largos:

Buscar texto
  • Usa el atajo Ctrl + F o ve a Inicio → Buscar.
  • Escribe la palabra o frase en el campo de búsqueda.
  • Word resaltará todas las coincidencias en el documento.
  • Usa las flechas para navegar entre los resultados.
Reemplazar texto
  • Usa el atajo Ctrl + H o ve a Inicio → Reemplazar.
  • Escribe el texto a buscar y el texto de reemplazo.
  • Usa Reemplazar para cambios individuales o Reemplazar todo para todos los casos.
  • Opciones avanzadas: distinguir mayúsculas, buscar palabras completas.

Insertar caracteres especiales y símbolos

Word permite insertar símbolos matemáticos, monetarios, flechas y más:

Insertar símbolos
  • Ve a Insertar → Símbolo.
  • Selecciona el símbolo deseado de la lista (ej: ©, ®, €, →).
  • Para símbolos frecuentes, asigna un atajo de teclado en Más símbolos → Atajo de teclado.
Insertar ecuaciones
  • Ve a Insertar → Ecuación.
  • Selecciona una ecuación predefinida o escribe la tuya usando la barra de herramientas de ecuaciones.
  • Incluye fracciones, integrales, matrices, símbolos griegos y más.
Atajos para símbolos comunes:
  • Alt + 0169: © (copyright).
  • Alt + 0174: ® (registro).
  • Alt + 0128: € (euro).
  • Alt + 26: → (flecha derecha).

Insertar saltos de línea y párrafo

Controla el flujo del texto con diferentes tipos de saltos:

Salto de línea
  • Usa Shift + Enter para un salto de línea sin crear un nuevo párrafo.
  • Útil para direcciones, listas o cuando necesitas mantener el texto en el mismo párrafo pero en una nueva línea.
Nuevo párrafo
  • Presiona Enter para crear un nuevo párrafo.
  • Word aplica automáticamente el espaciado entre párrafos según el estilo seleccionado.
Salto de página
  • Usa Ctrl + Enter para insertar un salto de página manual.
  • O ve a Insertar → Salto de página.
  • Útil para controlar dónde comienza una nueva página en informes o documentos largos.
Salto de sección
  • Ve a Diseño → Saltos → Salto de sección.
  • Permite cambiar el diseño (márgenes, orientación, encabezados) en diferentes partes del documento.
  • Tipos: Página siguiente, Continuo, Página par/impar.

Módulo 3. Formato de Texto y Párrafos

El formato adecuado mejora la legibilidad y el aspecto profesional de tus documentos. Aprende a aplicar fuentes, colores, alineación, sangrías, viñetas, estilos y más.

Tipos de letra, tamaño, color y efectos

Personaliza el aspecto del texto con estas opciones:

Fuentes y tamaño
  • Selecciona el texto y elige una fuente en la pestaña Inicio (ej: Arial, Calibri, Times New Roman).
  • Ajusta el tamaño de fuente (ej: 12pt para cuerpo, 16pt para títulos).
  • Usa Ctrl + Shift + P para abrir el selector de fuentes.
  • Para cambiar el tamaño rápidamente, usa Ctrl + [ (disminuir) o Ctrl + ] (aumentar).
Color y efectos
  • Cambia el color del texto o del fondo con el selector de colores en Inicio.
  • Aplica efectos como negrita (Ctrl + N), cursiva (Ctrl + K), subrayado (Ctrl + S).
  • Usa tachado, subíndice (X2) o superíndice (X2) para fórmulas o notas.
Consejo: Usa fuentes sans-serif (como Arial o Calibri) para documentos digitales y serif (como Times New Roman) para documentos impresos, ya que son más legibles en cada medio.

Alineación y espaciado del texto

Controla la distribución del texto en la página:

Alineación del texto
  • Izquierda (Ctrl + L): Alinea el texto al margen izquierdo.
  • Centro (Ctrl + E): Centra el texto entre los márgenes.
  • Derecha (Ctrl + R): Alinea el texto al margen derecho.
  • Justificar (Ctrl + J): Alinea el texto a ambos márgenes.
Espaciado entre líneas y párrafos
  • Ajusta el interlineado en Inicio → Espaciado entre líneas (1.0, 1.5, 2.0, etc.).
  • Configura el espaciado antes y después de los párrafos en Inicio → Espaciado de párrafo.
  • Usa Eliminar espacio después del párrafo para documentos compactos.

Sangrías, tabulaciones y márgenes

Organiza el texto con sangrías, tabulaciones y ajusta los márgenes del documento:

Sangrías
  • Aumenta la sangría con Tab o Ctrl + M.
  • Disminuye la sangría con Shift + Tab o Ctrl + Shift + M.
  • Usa la regla superior para ajustar sangrías de primera línea o sangrías francesas.
Tabulaciones
  • Establece tabulaciones en la regla superior haciendo clic donde desees colocarlas.
  • Cambia el tipo de tabulación (izquierda, centro, derecha, decimal) en el selector de la regla.
  • Usa Tab para mover el cursor a la siguiente tabulación.
Márgenes del documento
  • Ajusta los márgenes en Diseño → Márgenes (Normal, Estrecho, Moderado, Ancho).
  • Para márgenes personalizados, selecciona Márgenes personalizados.
  • Define márgenes superior, inferior, izquierdo y derecho en centímetros o pulgadas.

Viñetas y numeración

Organiza información en listas con viñetas o numeración:

Listas con viñetas
  • Selecciona el texto y haz clic en el botón Viñetas en la pestaña Inicio.
  • Usa el atajo Ctrl + Shift + L.
  • Personaliza el estilo de viñetas (círculos, cuadrados, flechas) en Inicio → Viñetas → Definir nueva viñeta.
Listas numeradas
  • Selecciona el texto y haz clic en el botón Numeración en la pestaña Inicio.
  • Personaliza el formato de numeración (1, 2, 3 o a, b, c) en Inicio → Numeración → Definir nuevo formato de número.
  • Para listas multinivel, usa el botón Lista multinivel.
Consejo: Para convertir texto existente en una lista, selecciona el texto y aplica viñetas o numeración. Word detectará automáticamente los elementos de la lista basándose en los saltos de línea.

Aplicar estilos rápidos y temas

Los estilos y temas ayudan a mantener la coherencia visual en todo el documento:

Estilos de texto
  • Aplica estilos predefinidos como Título 1 (Ctrl + Alt + 1), Título 2 (Ctrl + Alt + 2), o Normal.
  • Personaliza estilos en Inicio → Estilos → Modificar estilo.
  • Crea nuevos estilos para elementos recurrentes (ej: "Cita", "Nota al pie").
Temas del documento
  • Cambia el tema en Diseño → Temas para aplicar colores, fuentes y efectos coherentes.
  • Personaliza temas con tus colores y fuentes preferidas.
  • Guarda temas personalizados para reutilizarlos en otros documentos.
Buena práctica: Usa estilos para estructurar tu documento (títulos, subtítulos, cuerpo). Esto facilita la creación de tablas de contenido automáticas y la navegación.

Formato condicional con estilos personalizados

Automatiza el formato basado en reglas o condiciones:

Crear estilos personalizados
  • Ve a Inicio → Estilos → Crear un estilo.
  • Define el formato (fuente, tamaño, color, alineación, etc.).
  • Asigna un atajo de teclado para aplicar el estilo rápidamente.
  • Ejemplo: Crea un estilo "Destacado" con fondo amarillo y negrita para resaltar texto importante.
Formato condicional
  • Usa Inicio → Estilos → Administrar estilos para aplicar formato basado en condiciones.
  • Ejemplo: Aplica un estilo "Urgente" a todo el texto que contenga la palabra "importante".
  • Combina con macros para automatizar el formato en documentos largos.

Módulo 4. Diseño de Página y Maquetación

Configura el diseño de tus documentos para que se vean profesionales e impresos correctamente. Aprende a ajustar márgenes, orientación, saltos, encabezados, pies de página y más.

Configuración de página: márgenes, orientación y tamaño

Ajusta el diseño básico de la página para adaptarlo a tus necesidades:

Márgenes de la página
  • Ve a Diseño → Márgenes y elige entre opciones predefinidas (Normal, Estrecho, Moderado, Ancho).
  • Para márgenes personalizados, selecciona Márgenes personalizados.
  • Define márgenes superior, inferior, izquierdo y derecho en centímetros o pulgadas.
  • Usa el botón Vista previa para ver cómo afectan los cambios al documento.
Orientación y tamaño del papel
  • Cambia entre orientación Vertical o Horizontal en Diseño → Orientación.
  • Selecciona el tamaño del papel (Carta, A4, Legal, etc.) en Diseño → Tamaño.
  • Para tamaños personalizados, elige Más tamaños de papel.
Consejo: Para documentos que se imprimirán a doble cara, usa márgenes simétricos y considera añadir un margen interior adicional para encuadernación.

Saltos de página y secciones

Controla dónde comienza una nueva página o cambia el diseño en partes específicas del documento:

Saltos de página
  • Inserta un salto de página manual con Ctrl + Enter.
  • O ve a Insertar → Salto de página.
  • Útil para forzar el inicio de un nuevo capítulo o sección en una página nueva.
  • Los saltos de página se muestran como líneas punteadas en el modo Diseño de impresión.
Saltos de sección
  • Ve a Diseño → Saltos → Salto de sección.
  • Tipos de saltos:
    • Página siguiente: Comienza la nueva sección en la siguiente página.
    • Continuo: La nueva sección comienza en el mismo punto.
    • Página par/impar: La sección comienza en la siguiente página par o impar.
  • Permite cambiar márgenes, orientación o encabezados/pies en diferentes secciones.

Encabezados, pies de página y numeración de páginas

Añade información repetitiva en cada página, como títulos, fechas o números de página:

Insertar encabezados y pies
  • Ve a Insertar → Encabezado o Pie de página.
  • Elige un diseño predefinido o crea uno personalizado.
  • Los encabezados y pies se editan en un área separada del documento.
  • Puedes insertar:
    • Número de página.
    • Fecha y hora (automática o fija).
    • Título del documento.
    • Logotipos o imágenes.
Numeración de páginas
  • Ve a Insertar → Número de página.
  • Elige la posición (superior, inferior, márgenes) y el estilo de numeración.
  • Para personalizar, selecciona Formato de número de página.
  • Puedes iniciar la numeración desde un número diferente (ej: 1, 5, 10).
Consejo: Para documentos largos, usa encabezados diferentes en la primera página (ej: portadas) y páginas pares e impares para diseños de libro.

Portadas y páginas en blanco

Añade portadas profesionales o páginas en blanco para separar secciones:

Insertar una portada
  • Ve a Insertar → Portada.
  • Elige un diseño predefinido (ej: "Austera", "Elegante", "Moderna").
  • Personaliza el título, subtítulo, fecha, autor y otros campos.
  • Las portadas se insertan al inicio del documento y se actualizan automáticamente.
Insertar una página en blanco
  • Coloca el cursor donde desees insertar la página.
  • Presiona Ctrl + Enter para insertar un salto de página.
  • O ve a Insertar → Página en blanco.
  • Útil para separar capítulos o secciones en informes largos.

Fondos de página, bordes y marcas de agua

Añade elementos visuales para mejorar el diseño de tus documentos:

Color de página y bordes
  • Cambia el color de fondo en Diseño → Color de página.
  • Añade bordes decorativos en Diseño → Bordes de página.
  • Personaliza el estilo, color y ancho de los bordes.
  • Opciones de arte para bordes (ej: estrellas, líneas, diseños temáticos).
Marcas de agua
  • Ve a Diseño → Marca de agua.
  • Elige una marca predefinida (ej: "Confidencial", "Borrador", "Urgente").
  • O crea una personalizada con texto o imagen.
  • Ajusta la transparencia, tamaño y posición.
Uso práctico: Las marcas de agua son útiles para indicar el estado de un documento (ej: "Borrador", "Confidencial") o añadir un logotipo sutil en informes oficiales.

Módulo 5. Inserción de Elementos

Enriquece tus documentos con imágenes, formas, tablas, gráficos, cuadros de texto y más. Aprende a insertar y personalizar estos elementos para crear documentos visualmente atractivos y funcionales.

Imágenes: insertar, ajustar y dar formato

Añade imágenes para ilustrar tus documentos y ajusta su apariencia:

Insertar imágenes
  • Ve a Insertar → Imágenes y elige:
    • Este dispositivo: Para imágenes guardadas en tu equipo.
    • Imágenes en línea: Busca en Bing o OneDrive.
    • Iconos: Para insertar iconos vectoriales.
    • Modelos 3D: Para objetos tridimensionales.
  • Arrastra y suelta imágenes directamente desde el explorador de archivos.
Ajustar y recortar imágenes
  • Selecciona la imagen y usa los controladores para redimensionarla (mantén Shift para conservar proporciones).
  • Recorta la imagen con Formato de imagen → Recortar.
  • Ajusta el brillo, contraste y nitidez en Formato de imagen → Correcciones.
  • Aplica estilos artísticos en Formato de imagen → Estilos artísticos.
Formato y disposición
  • Ajusta el ajuste de texto (en línea, cuadrado, apretado, etc.) en Formato de imagen → Ajuste de texto.
  • Añade bordes, efectos (sombra, reflejo, resplandor) y estilos predefinidos.
  • Usa Formato de imagen → Posición para alinear la imagen con precisión.
  • Agrupa imágenes con otros objetos para moverlas juntas.
Alternativas y accesibilidad
  • Añade texto alternativo para que los lectores de pantalla describan la imagen.
  • Ve a Formato de imagen → Texto alternativo.
  • Incluye descripciones claras para usuarios con discapacidad visual.

Formas y SmartArt

Crea diagramas y elementos gráficos con formas y SmartArt:

Insertar formas
  • Ve a Insertar → Formas y elige entre líneas, rectángulos, círculos, flechas, etc.
  • Dibuja la forma arrastrando el cursor.
  • Personaliza el relleno, borde y efectos en Formato de forma.
  • Usa Shift al dibujar para mantener proporciones.
Crear diagramas con SmartArt
  • Ve a Insertar → SmartArt.
  • Elige un tipo de diagrama:
    • Lista: Para procesos o jerarquías simples.
    • Proceso: Para flujos de trabajo o pasos secuenciales.
    • Ciclo: Para procesos circulares o continuos.
    • Jerarquía: Para organigramas o estructuras organizativas.
  • Edita el texto en el panel de texto y personaliza colores y estilos.
Consejo: Usa SmartArt para convertir listas aburridas en diagramas visuales. Por ejemplo, transforma una lista de pasos en un diagrama de proceso o un organigrama.

Tablas: creación, diseño y formato

Organiza datos en tablas y aplícales formato profesional:

Crear una tabla
  • Ve a Insertar → Tabla y arrastra para seleccionar filas y columnas.
  • O haz clic en Insertar tabla para especificar el número exacto de filas y columnas.
  • Dibuja una tabla con el lápiz en Insertar → Tabla → Dibujar tabla.
Diseño y formato de tablas
  • Aplica estilos predefinidos en Diseño de tabla → Estilos de tabla.
  • Personaliza bordes, sombreados y colores de fila/columna.
  • Usa Diseño de tabla → Bandas para alternar colores en filas o columnas.
  • Ajusta el ancho de columnas arrastrando los bordes o en Diseño de tabla → Tamaño de celda.
Fórmulas en tablas
  • Coloca el cursor en la celda donde deseas el resultado.
  • Ve a Diseño de tabla → Fórmula.
  • Escribe la fórmula (ej: =SUM(ABOVE) para sumar los valores de arriba).
  • Usa funciones como PROMEDIO, MAX, MIN.
Convertir texto en tabla
  • Separa los datos con tabulaciones, comas o párrafos.
  • Selecciona el texto y ve a Insertar → Tabla → Convertir texto en tabla.
  • Elige el separador y ajusta el formato.

Gráficos: tipos, personalización y edición

Visualiza datos con gráficos dinámicos y personalizables:

Insertar un gráfico
  • Ve a Insertar → Gráfico.
  • Elige un tipo de gráfico:
    • Columna: Para comparar valores entre categorías.
    • Línea: Para mostrar tendencias a lo largo del tiempo.
    • Circular: Para mostrar proporciones de un total.
    • Barras: Similar a columnas, pero con barras horizontales.
    • Área: Para enfatizar el volumen de cambio.
  • Edita los datos en la hoja de cálculo integrada.
Personalizar gráficos
  • Cambia el diseño en Diseño de gráfico → Diseños de gráfico.
  • Ajusta colores, estilos y efectos en Formato de gráfico.
  • Añade títulos, etiquetas de datos y leyendas.
  • Cambia el tipo de gráfico en Diseño de gráfico → Cambiar tipo de gráfico.
Consejo: Para gráficos complejos, crea el gráfico en Excel y luego cópialo y pégalo en Word. Esto te permite aprovechar las funciones avanzadas de Excel para análisis de datos.

Cuadros de texto

Inserta texto en cualquier lugar del documento con cuadros de texto:

Insertar y formato
  • Ve a Insertar → Cuadro de texto y elige un diseño predefinido o dibuja uno.
  • Escribe o pega texto dentro del cuadro.
  • Personaliza el borde, relleno y efectos en Formato de forma.
  • Ajusta el ajuste de texto para que el texto fluya alrededor del cuadro.
Vincular cuadros de texto
  • Crea un segundo cuadro de texto.
  • Haz clic en el borde del primer cuadro y selecciona Crear vínculo (icono de cadena).
  • Haz clic en el segundo cuadro para vincularlos.
  • El texto fluirá automáticamente del primer cuadro al segundo.
Uso práctico: Los cuadros de texto son ideales para diseñar folletos, newsletters o documentos con diseño de revista, donde el texto debe fluir alrededor de imágenes o en columnas.

WordArt y efectos visuales

Añade texto decorativo y efectos para destacar títulos o secciones:

Insertar WordArt
  • Ve a Insertar → WordArt y elige un estilo.
  • Escribe el texto y ajusta la fuente, tamaño y color.
  • Personaliza el contorno, relleno y efectos 3D en Formato de WordArt.
Efectos visuales
  • Aplica sombras, reflejos o resplandores a texto o formas.
  • Usa efectos 3D para dar profundidad a títulos o logotipos.
  • Combina WordArt con formas y cuadros de texto para diseños creativos.

Inserción de vínculos e hipervínculos

Añade enlaces a páginas web, correos, archivos o lugares dentro del documento:

Insertar hipervínculos
  • Selecciona el texto o imagen que será el enlace.
  • Usa el atajo Ctrl + K o ve a Insertar → Hipervínculo.
  • Elige el tipo de vínculo:
    • Archivo o página web existente.
    • Lugar en este documento (para saltar a secciones).
    • Dirección de correo electrónico.
    • Nuevo documento.
  • Personaliza el texto a mostrar y la dirección del vínculo.
Gestionar hipervínculos
  • Edita un vínculo haciendo clic derecho sobre él y seleccionando Editar hipervínculo.
  • Elimina un vínculo con clic derecho → Quitar hipervínculo.
  • Cambia el estilo de los vínculos en Inicio → Estilos → Hipervínculo.
Consejo: Usa hipervínculos para crear tablas de contenido interactivas o índices que permitan navegar fácilmente en documentos largos.

Inserción de ecuaciones y símbolos especiales

Añade fórmulas matemáticas, símbolos científicos o caracteres especiales:

Insertar ecuaciones
  • Ve a Insertar → Ecuación.
  • Selecciona una ecuación predefinida o escribe la tuya usando la barra de herramientas de ecuaciones.
  • Incluye:
    • Fracciones y radicales.
    • Símbolos griegos (α, β, γ).
    • Operadores (∑, ∏, ∫).
    • Matrices y vectores.
  • Convierte ecuaciones a formato profesional (LaTeX) si es necesario.
Insertar símbolos
  • Ve a Insertar → Símbolo.
  • Elige entre símbolos recientes o más símbolos.
  • Busca por categoría (ej: monetarios, matemáticos, flechas).
  • Asigna atajos de teclado a símbolos frecuentes.
Atajos para símbolos comunes:
  • Alt + 0169: © (copyright).
  • Alt + 0174: ® (registro).
  • Alt + 0128: € (euro).
  • Alt + 26: → (flecha derecha).

Módulo 6. Herramientas de Revisión

Revisa y perfecciona tus documentos con herramientas de ortografía, gramática, sinónimos, traducción, comentarios y control de cambios. Ideal para trabajar en equipo o pulir documentos importantes.

Ortografía y gramática automática

Corrige errores y mejora la claridad de tus documentos:

Revisar ortografía y gramática
  • Usa el atajo F7 o ve a Revisar → Ortografía y gramática.
  • Word resalta errores con líneas rojas (ortografía) y azules (gramática).
  • Haz clic derecho sobre una palabra resaltada para ver sugerencias.
  • Configura opciones avanzadas en Archivo → Opciones → Revisión.
Opciones de revisión
  • Ignora errores específicos con Omitir una vez o Omitir todas.
  • Añade palabras al diccionario con Agregar al diccionario.
  • Cambia el idioma de revisión en Revisar → Idioma → Establecer idioma de corrección.
  • Activa o desactiva la revisión automática según tus necesidades.
Consejo: Usa el Lector Inmersivo (en la pestaña Vista) para mejorar la legibilidad y detectar errores en documentos largos.

Diccionario de sinónimos y traductor

Enriquece tu vocabulario y traduce texto directamente en Word:

Buscar sinónimos
  • Selecciona la palabra y usa el atajo Shift + F7.
  • O haz clic derecho sobre la palabra y selecciona Sinónimos.
  • Word muestra una lista de sinónimos; haz clic en uno para reemplazar la palabra.
  • Usa Buscar más sinónimos en línea para opciones adicionales.
Traducir texto
  • Selecciona el texto a traducir.
  • Ve a Revisar → Traductor.
  • Elige los idiomas de origen y destino.
  • Word muestra la traducción en un panel; haz clic en Insertar para reemplazar el texto original.

Revisión de idioma y estilo

Asegúrate de que tu documento esté escrito en el idioma correcto y con un estilo consistente:

Configurar el idioma
  • Selecciona el texto y ve a Revisar → Idioma → Establecer idioma de corrección.
  • Elige el idioma (ej: Español, Inglés, Francés).
  • Marca No volver a comprobar la ortografía o gramática si es necesario.
  • Descarga paquetes de idioma adicionales si no están instalados.
Estilo y claridad
  • Usa el Editor de Word (pestaña Revisar) para mejorar la claridad y concisión.
  • El Editor sugiere mejoras en:
    • Corrección (ortografía y gramática).
    • Claridad (frases complejas, vocabulario).
    • Concisión (repeticiones, palabras innecesarias).
    • Formalidad (tono adecuado al contexto).
  • Haz clic en las sugerencias para aplicarlas automáticamente.

Comentarios y control de cambios

Colabora con otros revisores y realiza un seguimiento de las modificaciones:

Añadir y gestionar comentarios
  • Selecciona el texto y ve a Revisar → Nuevo comentario.
  • Escribe tu comentario en el globo que aparece.
  • Responde a comentarios existentes con Responder.
  • Marca comentarios como Resuelto una vez atendidos.
  • Elimina comentarios con clic derecho → Eliminar comentario.
Control de cambios
  • Activa el control de cambios en Revisar → Control de cambios.
  • Todas las ediciones (inserciones, eliminaciones, cambios de formato) se marcarán.
  • Configura opciones en Revisar → Control de cambios → Opciones de control de cambios.
  • Acepta o rechaza cambios con Revisar → Aceptar/Rechazar.
Buena práctica: Usa comentarios para sugerencias y control de cambios para ediciones directas. Esto facilita la revisión y evita confusiones en documentos colaborativos.

Comparar y combinar documentos

Combina cambios de múltiples versiones o compara documentos para ver diferencias:

Comparar documentos
  • Ve a Revisar → Comparar → Comparar documentos.
  • Selecciona el documento original y el revisado.
  • Word muestra las diferencias en un nuevo documento con cambios resaltados.
  • Usa la barra de herramientas para navegar entre cambios y aceptarlos o rechazarlos.
Combinar documentos
  • Ve a Revisar → Comparar → Combinar documentos.
  • Selecciona los documentos a combinar.
  • Word fusiona los cambios de múltiples revisores en un solo documento.
  • Resuelve conflictos manualmente si hay cambios contradictorios.
Consejo: Antes de combinar documentos, asegúrate de que todos los revisores hayan usado el control de cambios para que Word pueda rastrear quién hizo cada modificación.

Módulo 7. Tablas y Formularios

Organiza datos en tablas profesionales y crea formularios interactivos para recopilar información de manera estructurada. Ideal para informes, encuestas, registros y más.

Creación de tablas desde cero

Inserta y personaliza tablas para organizar datos:

Insertar una tabla
  • Ve a Insertar → Tabla.
  • Arrastra para seleccionar el número de filas y columnas.
  • O haz clic en Insertar tabla para especificar el tamaño exacto.
  • Dibuja una tabla con el lápiz en Insertar → Tabla → Dibujar tabla.
Ajustar filas y columnas
  • Añade o elimina filas/columnas con clic derecho sobre la tabla.
  • Arrastra los bordes para ajustar el ancho de columnas o alto de filas.
  • Usa Diseño de tabla → Tamaño de celda para ajustes precisos.
  • Distribuye filas o columnas equitativamente con Distribuir filas/columnas.

Convertir texto en tabla y viceversa

Transforma texto estructurado en tablas y viceversa para mayor flexibilidad:

Convertir texto en tabla
  • Separa los datos con tabulaciones, comas, punto y coma o párrafos.
  • Selecciona el texto y ve a Insertar → Tabla → Convertir texto en tabla.
  • Elige el separador de texto (tabulaciones, comas, etc.).
  • Word creará una tabla con los datos organizados en filas y columnas.
Ejemplo: 
Nombre    Edad    Ciudad
Ana      28      Madrid
Luis     34      Barcelona

Seleccionar este texto y convertirlo en tabla con "Tabulación" como separador.

Convertir tabla en texto
  • Selecciona la tabla y ve a Diseño de tabla → Convertir en texto.
  • Elige el separador (párrafos, tabulaciones, comas).
  • Word convertirá cada celda en un elemento de texto separado.

Dar formato a filas, columnas y celdas

Personaliza el aspecto de tus tablas para mejorar la legibilidad y el diseño:

Estilos de tabla
  • Aplica estilos predefinidos en Diseño de tabla → Estilos de tabla.
  • Elige entre diseños con o sin bordes, colores alternados, etc.
  • Personaliza los colores de la tabla en Diseño de tabla → Bordes → Color de borde.
Formato de celdas
  • Selecciona las celdas y ajusta el formato en Inicio (fuente, alineación, color).
  • Cambia el color de relleno en Diseño de tabla → Sombreado.
  • Combina celdas con Diseño de tabla → Combinar celdas.
  • Divide celdas con Diseño de tabla → Dividir celdas.
Bordes y líneas
  • Aplica bordes a celdas seleccionadas en Diseño de tabla → Bordes.
  • Elige el estilo, color y grosor de los bordes.
  • Usa Sin bordes para ocultar líneas en celdas específicas.
Alineación y dirección del texto
  • Alinea el texto en las celdas (izquierda, centro, derecha, justificar).
  • Cambia la dirección del texto (horizontal, vertical, girado) en Diseño de tabla → Dirección del texto.
  • Ajusta el margen interno de las celdas para mejorar la legibilidad.

Sumar o calcular dentro de una tabla

Realiza cálculos básicos directamente en las celdas de tus tablas:

Insertar fórmulas
  • Coloca el cursor en la celda donde deseas el resultado.
  • Ve a Diseño de tabla → Fórmula.
  • Word inserta automáticamente =SUM(ABOVE) para sumar los valores de arriba.
  • Edita la fórmula según tus necesidades (ej: =PRODUCT(LEFT) para multiplicar).
Funciones disponibles
  • SUM: Suma de valores.
  • AVERAGE: Promedio.
  • MIN/MAX: Valor mínimo/máximo.
  • COUNT: Contar celdas no vacías.
  • PRODUCT: Multiplicación.
Nota: Las fórmulas en tablas de Word son básicas. Para cálculos complejos, considera usar Excel y luego copiar la tabla a Word.

Crear formularios interactivos

Diseña formularios con campos editables para encuestas, registros o documentos legales:

Insertar campos de formulario
  • Activa la pestaña Programador en Archivo → Opciones → Personalizar cinta.
  • Coloca el cursor donde desees el campo y elige:
    • Cuadro de texto: Para respuestas abiertas.
    • Casilla de verificación: Para opciones sí/no.
    • Lista desplegable: Para seleccionar entre opciones predefinidas.
    • Selector de fecha: Para ingresar fechas.
  • Configura las propiedades de cada campo (ej: formato, valor predeterminado).
Protección del formulario
  • Ve a Revisar → Restringir edición.
  • Selecciona Permitir solo este tipo de edición en el documento.
  • Marca Rellenar formularios y haz clic en Sí, aplicar protección.
  • Establece una contraseña para evitar cambios no autorizados.
Consejo: Usa formularios para crear contratos, encuestas o registros que otros puedan completar sin modificar la estructura del documento.

Campos de texto, listas desplegables y casillas

Detalles sobre los tipos de campos para formularios:

Cuadros de texto
  • Ideal para respuestas abiertas (ej: nombres, direcciones, comentarios).
  • Configura el formato (ej: solo números, fecha, texto enriquecido).
  • Establece un texto predeterminado o un mensaje de ayuda.
Listas desplegables
  • Útil para opciones predefinidas (ej: sí/no, países, categorías).
  • Edita las opciones en Propiedades → Opciones de lista desplegable.
  • Permite seleccionar múltiples opciones si es necesario.
Casillas de verificación
  • Para opciones binarias (ej: acepto los términos, asistiré al evento).
  • Configura el tamaño y el valor predeterminado (marcado/desmarcado).
Selectores de fecha
  • Facilita la selección de fechas sin errores de formato.
  • Configura el formato de fecha (dd/mm/aaaa, mm/dd/aaaa, etc.).

Protección del formulario

Evita modificaciones no autorizadas en tus formularios:

Restringir edición
  • Ve a Revisar → Restringir edición.
  • Selecciona Permitir solo este tipo de edición en el documento.
  • Marca Rellenar formularios.
  • Haz clic en Sí, aplicar protección y establece una contraseña.
Permisos avanzados
  • Configura permisos específicos para diferentes usuarios.
  • Usa Archivo → Información → Proteger documento para opciones avanzadas.
  • Restringe la impresión o copia del contenido si es necesario.
Importante: Siempre guarda una copia del formulario sin protección por si necesitas realizar cambios en el futuro.

Módulo 8. Diseño Profesional de Documentos

Crea documentos con un diseño impecable: cartas, informes, currículums, folletos y más. Utiliza plantillas, estilos, tablas de contenido y herramientas avanzadas para lograr resultados profesionales.

Diseño de cartas, informes y currículums

Plantillas y estructuras para documentos formales:

Cartas formales
  • Usa plantillas predefinidas en Archivo → Nuevo (busca "carta").
  • Incluye:
    • Encabezado con tu información y la del destinatario.
    • Fecha y referencia (si aplica).
    • Saludo formal (ej: "Estimado/a [Nombre]").
    • Cuerpo del mensaje (claro y conciso).
    • Despedida y firma.
  • Aplica estilos consistentes para títulos y párrafos.
Informes académicos o técnicos
  • Usa plantillas de informes o crea una estructura personalizada.
  • Incluye:
    • Portada con título, autor, fecha y logotipos.
    • Índice o tabla de contenido automática.
    • Resumen ejecutivo (si aplica).
    • Secciones numeradas con títulos y subtítulos.
    • Gráficos, tablas y figuras con pies explicativos.
    • Conclusiones y bibliografía.
  • Usa estilos como "Título 1", "Título 2" para generar la tabla de contenido automáticamente.
Currículums vitae
  • Busca plantillas de currículum en Archivo → Nuevo.
  • Secciones esenciales:
    • Información personal (nombre, contacto, perfil profesional).
    • Experiencia laboral (en orden cronológico inverso).
    • Formación académica.
    • Habilidades y competencias.
    • Idiomas, certificaciones, proyectos relevantes.
  • Usa viñetas para listas y mantén un diseño limpio y profesional.
Consejos de diseño
  • Mantén la coherencia en fuentes, colores y espaciado.
  • Usa negritas y cursivas para enfatizar, pero sin excederte.
  • Incluye espacio en blanco para mejorar la legibilidad.
  • Guarda el documento en PDF para compartirlo sin perder el formato.

Creación de plantillas personalizadas

Guarda diseños como plantillas para reutilizarlos en el futuro:

Guardar como plantilla
  • Diseña tu documento con todos los elementos necesarios (encabezados, estilos, logos).
  • Ve a Archivo → Guardar como.
  • Selecciona Plantilla de Word (*.dotx) como tipo de archivo.
  • Guarda en la carpeta Plantillas personalizadas de Office para acceso rápido.
Usar plantillas personalizadas
  • Ve a Archivo → Nuevo → Personalizado.
  • Selecciona tu plantilla y crea un nuevo documento basado en ella.
  • Las plantillas conservan estilos, macros y configuraciones.
Consejo: Crea plantillas para documentos que uses frecuentemente, como facturas, actas de reunión o informes mensuales, para ahorrar tiempo.

Diseño de folletos, trípticos y carteles

Maquetación avanzada para materiales promocionales o informativos:

Folletos y trípticos
  • Configura el documento en Diseño → Tamaño → Más tamaños de papel (ej: A4 doblado en tres).
  • Usa Diseño → Columnas para crear 2 o 3 columnas.
  • Inserta cuadros de texto para contenido flexible.
  • Incluye imágenes, logos y gráficos con ajuste de texto alrededor.
  • Usa colores y fuentes llamativas, pero mantén la legibilidad.
Carteles y afiches
  • Configura el tamaño del papel según el cartel (ej: A3, A2).
  • Usa Diseño → Orientación → Horizontal.
  • Inserta un cuadro de texto grande para el título principal.
  • Añade imágenes de alta resolución y ajusta el brillo/contraste si es necesario.
  • Incluye información clave (fecha, lugar, contacto) en un tamaño legible desde la distancia.
Consejo: Para folletos, usa la opción Diseño → Saltos → Salto de sección para crear páginas enfrentadas (como en un libro).

Uso de secciones y columnas

Organiza documentos complejos con secciones y columnas:

Secciones del documento
  • Usa saltos de sección para:
    • Cambiar la orientación de algunas páginas (ej: horizontal para tablas grandes).
    • Aplicar encabezados/pies diferentes en partes del documento.
    • Numerar páginas de manera distinta (ej: romanos en el índice, arábigos en el contenido).
  • Inserta saltos en Diseño → Saltos → Salto de sección.
Columnas de texto
  • Ve a Diseño → Columnas y elige el número de columnas (1 a 3).
  • Personaliza el ancho y espaciado entre columnas.
  • Usa líneas entre columnas para mejorar la legibilidad.
  • Inserta saltos de columna manuales con Diseño → Saltos → Salto de columna.

Tablas de contenido automáticas

Crea índices dinámicos basados en los estilos de tu documento:

Insertar tabla de contenido
  • Aplica estilos de título (Título 1, Título 2, etc.) a los encabezados de tu documento.
  • Coloca el cursor donde deseas la tabla de contenido.
  • Ve a Referencias → Tabla de contenido y elige un diseño.
  • Word generará automáticamente la tabla con los títulos y números de página.
Actualizar y personalizar
  • Actualiza la tabla haciendo clic en ella y seleccionando Actualizar tabla.
  • Elige entre actualizar solo los números de página o toda la tabla.
  • Personaliza el formato (fuentes, tabulaciones, niveles mostrados) en Referencias → Tabla de contenido → Tabla de contenido personalizada.
Consejo: Usa la opción Mostrar niveles para decidir qué niveles de título incluir (ej: solo hasta Título 3).

Índices, notas al pie y citas bibliográficas

Añade referencias académicas y notas explicativas:

Notas al pie y notas al final
  • Coloca el cursor donde deseas la nota.
  • Ve a Referencias → Insertar nota al pie o Insertar nota al final.
  • Word inserta un superíndice y te lleva al área de notas para escribir el contenido.
  • Personaliza el formato de las notas en Referencias → Notas al pie → Configuración de notas al pie.
Citas y bibliografía
  • Ve a Referencias → Insertar cita.
  • Elige el estilo de cita (APA, MLA, Chicago, etc.).
  • Añade una nueva fuente con los detalles bibliográficos (autor, título, año, etc.).
  • Inserta la cita en el texto y Word generará la bibliografía automáticamente.
  • Actualiza la bibliografía con Referencias → Bibliografía → Actualizar citas y bibliografía.

Referencias cruzadas y pies de ilustración

Crea enlaces internos y leyendas para figuras y tablas:

Referencias cruzadas
  • Coloca el cursor donde deseas la referencia.
  • Ve a Referencias → Referencia cruzada.
  • Elige el tipo de referencia (título, figura, tabla, etc.) y el elemento específico.
  • Selecciona si deseas mostrar el número de página, el texto del título, etc.
  • Word insertará un enlace que se actualiza automáticamente.
Pies de ilustración
  • Selecciona la imagen o tabla.
  • Ve a Referencias → Insertar título.
  • Elige la etiqueta (Figura, Tabla, Ecuación) y escribe el texto del pie.
  • Personaliza el formato (numeración, posición, fuente) en Referencias → Insertar título → Título.
  • Word generará automáticamente leyendas como "Figura 1: Descripción".
Consejo: Usa referencias cruzadas para crear índices de figuras o tablas de contenido detalladas en documentos técnicos.

Módulo 9. Combinar Correspondencia

Genera documentos personalizados en masa, como cartas, etiquetas, sobres o correos electrónicos, utilizando una plantilla y una fuente de datos (Excel, Access, Outlook). Ideal para comunicaciones masivas con un toque personal.

¿Qué es la combinación de correspondencia?

La combinación de correspondencia permite:

  • Unir un documento principal (plantilla) con una fuente de datos (ej: lista de clientes en Excel).
  • Generar múltiples copias personalizadas (ej: cartas con nombres diferentes, etiquetas con direcciones únicas).
  • Automatizar procesos repetitivos y reducir errores manuales.
Elementos clave
  • Documento principal: Contiene el texto fijo y los campos de combinación (ej: "Estimado [Nombre]").
  • Fuente de datos: Base de datos con la información variable (ej: Excel, Access, Outlook).
  • Documento combinado: Resultado final con todos los documentos personalizados.

Crear cartas personalizadas con base de datos

Pasos para generar cartas personalizadas:

Preparar el documento principal
  • Abre un nuevo documento en Word.
  • Escribe el texto fijo de la carta (ej: encabezado, cuerpo, despedida).
  • Deja espacios para los campos personalizados (ej: nombre, dirección).
Iniciar la combinación
  • Ve a Correspondencia → Iniciar combinación de correspondencia → Cartas.
  • Selecciona Seleccionar destinatarios → Usar lista existente.
  • Elige tu fuente de datos (archivo Excel, base de datos Access, contactos de Outlook).
Insertar campos de combinación
  • Coloca el cursor donde deseas insertar un campo (ej: nombre del destinatario).
  • Ve a Correspondencia → Insertar campo de combinación.
  • Selecciona el campo correspondiente (ej: "Nombre", "Apellido", "Dirección").
  • Repite para todos los campos variables.
Vista previa y finalización
  • Usa Correspondencia → Vista previa de resultados para revisar.
  • Navega entre registros con las flechas de vista previa.
  • Ve a Correspondencia → Finalizar y combinar → Editar documentos individuales.
  • Elige si deseas combinar todos los registros o solo algunos.
  • Word generará un nuevo documento con todas las cartas personalizadas.
Consejo: Usa la opción Reglas en la pestaña Correspondencia para añadir lógica condicional (ej: "Si el género es femenino, usar 'Estimada'; si no, 'Estimado').

Combinar etiquetas y sobres

Genera etiquetas para sobres o productos, y prepara sobres con direcciones personalizadas:

Etiquetas de dirección
  • Ve a Correspondencia → Iniciar combinación de correspondencia → Etiquetas.
  • Selecciona el proveedor de etiquetas (ej: Avery) y el número de producto.
  • Word mostrará una hoja con el diseño de las etiquetas.
  • Inserta los campos de dirección en la primera etiqueta.
  • Usa Correspondencia → Actualizar etiquetas para replicar en todas.
  • Finaliza con Correspondencia → Finalizar y combinar.
Sobres
  • Ve a Correspondencia → Iniciar combinación de correspondencia → Sobres.
  • Configura el tamaño del sobre y la posición de la dirección.
  • Inserta los campos de dirección del remitente y destinatario.
  • Usa Correspondencia → Finalizar y combinar para imprimir o generar los sobres.
Consejo: Para etiquetas, usa la opción Vista previa de resultados para asegurarte de que el texto quepa correctamente en cada etiqueta antes de imprimir.

Combinar con Excel u otras fuentes de datos

Usa diferentes orígenes de datos para personalizar tus documentos:

Excel como fuente de datos
  • Prepara tu archivo Excel con una fila de encabezados (ej: Nombre, Apellido, Email).
  • Guarda el archivo y ciérralo antes de usarlo en Word.
  • En Word, selecciona Usar lista existente y elige tu archivo Excel.
  • Selecciona la hoja y el rango de celdas que contienen los datos.
Otras fuentes de datos
  • Access: Usa consultas o tablas como origen.
  • Outlook: Selecciona contactos directamente.
  • Lista nueva: Crea una lista de destinatarios desde cero en Word.
  • Archivo de texto: Usa archivos CSV o TXT con datos separados por comas o tabulaciones.
Nota: Asegúrate de que los nombres de los encabezados en tu fuente de datos coincidan con los campos que insertas en Word (ej: "Nombre" en Excel debe ser "Nombre" en Word).

Módulo 10. Funciones Avanzadas

Automatiza tareas repetitivas, protege documentos y utiliza herramientas avanzadas como macros, campos, formularios electrónicos y más. Ideal para usuarios que buscan maximizar su productividad.

Uso de macros y automatización

Las macros permiten grabar y reproducir acciones para ahorrar tiempo:

Grabar una macro
  • Ve a Vista → Macros → Grabar macro.
  • Asigna un nombre descriptivo y elige donde guardarla (documento actual o todas las plantillas).
  • Realiza las acciones que deseas automatizar (ej: aplicar formato, insertar tabla).
  • Detén la grabación con Vista → Macros → Detener grabación.
Ejecutar y gestionar macros
  • Ejecuta una macro con Alt + F8 o desde Vista → Macros → Ver macros.
  • Asigna un atajo de teclado o un botón en la barra de herramientas para acceso rápido.
  • Edita el código VBA de la macro para personalizarla (requiere conocimientos de programación).
  • Elimina macros no utilizadas para mantener el documento limpio.
Ejemplos prácticos de macros
  • Formato rápido: Aplicar un conjunto de estilos a un texto seleccionado.
  • Inserción automática: Añadir una tabla con formato predefinido en un clic.
  • Limpieza de documento: Eliminar espacios dobles o formatos inconsistentes.
  • Generación de informes: Extraer datos de una tabla y crear un resumen.
Seguridad con macros
  • Las macros pueden contener código malicioso. Solo ejecuta macros de fuentes confiables.
  • Configura la seguridad de macros en Archivo → Opciones → Centro de confianza → Configuración del Centro de confianza → Configuración de macros.
  • Opciones recomendadas:
    • Desactivar todas las macros sin notificación (más seguro).
    • Desactivar macros con notificación (recomendado).
    • Habilitar todas las macros (solo para documentos confiables).

Protección de documentos

Protege tus documentos contra cambios no autorizados o accesos no deseados:

Contraseña para abrir o modificar
  • Ve a Archivo → Información → Proteger documento → Cifrar con contraseña.
  • Establece una contraseña para abrir el documento.
  • Para restringir ediciones, usa Proteger documento → Restringir edición.
  • Elige qué tipo de cambios permitir (ej: solo comentarios, solo rellenar formularios).
Marcas de agua y firmas digitales
  • Añade una marca de agua en Diseño → Marca de agua (ej: "Confidencial", "Borrador").
  • Inserta una firma digital en Insertar → Firma → Firmas de Microsoft Office.
  • Configura permisos para evitar la impresión o copia del contenido.
Importante: No olvides tus contraseñas. Word no puede recuperarlas si las pierdes.

Seguimiento de versiones

Controla los cambios en tus documentos y recupera versiones anteriores:

Historial de versiones en OneDrive
  • Guarda el documento en OneDrive o SharePoint.
  • Abre el historial de versiones en Archivo → Información → Historial de versiones.
  • Selecciona una versión anterior para verla o restaurarla.
  • Compara versiones para ver qué cambios se realizaron.
Comparar documentos
  • Ve a Revisar → Comparar → Comparar documentos.
  • Selecciona el documento original y el revisado.
  • Word muestra las diferencias en un nuevo documento con cambios resaltados.
  • Usa la barra de herramientas para navegar entre cambios y aceptarlos o rechazarlos.

Inserción de campos y códigos

Los campos permiten insertar información dinámica que se actualiza automáticamente:

Tipos de campos comunes
  • Fecha y hora: Inserta la fecha actual que se actualiza automáticamente.
  • Número de página: Para encabezados o pies de página.
  • Título del documento: Muestra el nombre del archivo.
  • Fórmulas: Cálculos en tablas (ej: suma, promedio).
  • Referencias cruzadas: Enlaces a otros elementos del documento.
Insertar y actualizar campos
  • Coloca el cursor donde deseas el campo.
  • Ve a Insertar → Campo.
  • Selecciona la categoría y el campo específico (ej: Date, Page, NumPages).
  • Configura el formato (ej: fecha en formato "dd/mm/aaaa").
  • Actualiza los campos seleccionándolos y presionando F9.
Consejo: Usa el campo Date con formato dddd, d "de" MMMM "de" yyyy para mostrar fechas como "Lunes, 26 de octubre de 2025".

Formularios electrónicos avanzados

Crea formularios interactivos con lógica y validación de datos:

Campos avanzados
  • Usa cuadros de texto con formato para fechas, números o texto enriquecido.
  • Añade listas desplegables con opciones dinámicas (ej: mostrar ciudades según el país seleccionado).
  • Configura casillas de verificación con valores personalizados.
  • Inserta botones de acción para navegar entre secciones del formulario.
Validación y protección
  • Establece reglas de validación para campos (ej: solo números, rango de fechas).
  • Usa mensajes de entrada y error para guiar al usuario.
  • Protege el formulario con Revisar → Restringir edición.
  • Guarda el formulario como plantilla (.dotx) para reutilizarlo.
Consejo: Para formularios complejos, considera usar Microsoft Forms o Google Forms y luego exportar las respuestas a Word.

Módulo 11. Trabajo Colaborativo y Nube

Colabora en tiempo real con otros usuarios, guarda documentos en OneDrive o SharePoint, y comparte archivos de manera segura. Aprende a usar las herramientas de colaboración integradas en Word 2025.

Guardar en OneDrive o SharePoint

Almacena tus documentos en la nube para acceder desde cualquier lugar y colaborar con otros:

Guardar en OneDrive
  • Ve a Archivo → Guardar como.
  • Selecciona OneDrive como ubicación.
  • Elige una carpeta existente o crea una nueva.
  • Activa el AutoGuardado para sincronizar cambios automáticamente.
  • Configura el guardado automático en Archivo → Opciones → Guardar.
Beneficios de OneDrive
  • Acceso a tus documentos desde cualquier dispositivo con internet.
  • Historial de versiones para recuperar cambios anteriores.
  • Colaboración en tiempo real con otros usuarios.
  • Protección contra pérdida de datos con copias de seguridad automáticas.
Consejo: Usa la carpeta OneDrive - [Tu Empresa] si trabajas en un entorno corporativo, para mantener los documentos dentro del dominio de tu organización.

Compartir documentos en línea

Comparte tus documentos con otros usuarios y controla los permisos de acceso:

Compartir desde Word
  • Haz clic en el botón Compartir en la esquina superior derecha.
  • Ingresa las direcciones de correo de los destinatarios.
  • Elige el nivel de permiso:
    • Puede editar: Permite modificar el documento.
    • Puede ver: Solo lectura.
  • Añade un mensaje opcional y envía la invitación.
Opciones avanzadas
  • Genera un enlace compartible para enviar por correo o mensajería.
  • Configura la fecha de caducidad del enlace.
  • Establece una contraseña para acceder al documento.
  • Bloquea el enlace para evitar que se reenvíe a otros usuarios.

Colaboración en tiempo real

Trabaja simultáneamente con otros usuarios en el mismo documento:

Coautoría en Word
  • Todos los colaboradores deben tener el documento guardado en OneDrive o SharePoint.
  • Los cambios se sincronizan en tiempo real y se muestran con colores diferentes por usuario.
  • Usa el panel Personas para ver quién está editando y dónde.
  • Los conflictos se resuelven automáticamente, priorizando el último cambio.
Comentarios y chat
  • Añade comentarios con Revisar → Nuevo comentario.
  • Responde a comentarios existentes para mantener conversaciones.
  • Usa el chat integrado (en la versión web) para comunicarte con los colaboradores.
  • Marca comentarios como resueltos una vez atendidos.
Consejo: Usa la función @mención en los comentarios para notificar a un colaborador específico (ej: "@Andrés, ¿puedes revisar esta sección?").

Control de versiones y comentarios en grupo

Gestiona las diferentes versiones de un documento y organízate con tu equipo:

Historial de versiones
  • Ve a Archivo → Información → Historial de versiones.
  • Selecciona una versión anterior para verla o restaurarla.
  • Compara versiones para ver qué cambios se realizaron.
  • Descarga versiones anteriores si es necesario.
Notificaciones y alertas
  • Configura notificaciones por correo para cambios importantes.
  • Recibe alertas cuando alguien comente o edite el documento.
  • Revisa el historial de actividad para ver quién hizo qué y cuándo.
Importante: El historial de versiones solo está disponible para documentos guardados en OneDrive o SharePoint.

Módulo 12. Impresión y Exportación

Prepara tus documentos para imprimir o exportar a otros formatos como PDF, HTML o XPS. Ajusta la configuración de página, calidad de impresión y opciones de exportación para obtener los mejores resultados.

Vista preliminar e impresión

Revisa y ajusta tu documento antes de imprimir:

Vista preliminar
  • Usa el atajo Ctrl + F2 o ve a Archivo → Imprimir.
  • Revisa el diseño, márgenes y saltos de página.
  • Usa el zoom para inspeccionar detalles.
  • Navega entre páginas con las flechas o el panel de miniaturas.
Opciones de impresión
  • Selecciona la impresora y el rango de páginas a imprimir.
  • Elige entre imprimir todas las páginas, página actual o páginas específicas.
  • Configura el número de copias y la orientación (vertical/horizontal).
  • Usa Imprimir a doble cara para ahorrar papel.
Configuración avanzada
  • Ajusta el tamaño del papel y los márgenes.
  • Configura la calidad de impresión (borrador, estándar, alta).
  • Elige imprimir en escala de grises o color.
  • Usa imprimir marcas de agua o fondos si es necesario.
Impresión de sobres y etiquetas
  • Para sobres, usa Correspondencia → Sobres.
  • Para etiquetas, usa Correspondencia → Etiquetas.
  • Configura el tamaño y la posición según el tipo de sobre o etiqueta.

Configuración de impresora y márgenes

Ajusta la configuración para obtener los mejores resultados de impresión:

Seleccionar impresora
  • Ve a Archivo → Imprimir.
  • Selecciona la impresora deseada en el menú desplegable.
  • Si la impresora no está lista, haz clic en Agregar impresora.
  • Configura las propiedades de la impresora (calidad, tipo de papel, etc.).
Ajustar márgenes
  • Ve a Diseño → Márgenes.
  • Elige entre márgenes predefinidos (Normal, Estrecho, Moderado, Ancho).
  • Para márgenes personalizados, selecciona Márgenes personalizados.
  • Ajusta los márgenes superior, inferior, izquierdo y derecho.
  • Usa la opción Márgenes simétricos para documentos a doble cara.
Consejo: Usa la opción Vista de lectura (Vista → Modo de lectura) para revisar cómo se verá el documento en dispositivos móviles o tablets.

Exportar a PDF y otros formatos

Convierte tus documentos a otros formatos para compartir o archivar:

Exportar a PDF
  • Ve a Archivo → Exportar → Crear PDF/XPS.
  • Elige la ubicación y el nombre del archivo.
  • Configura opciones como:
    • Incluir marcas de revisión.
    • Optimizar para tamaño o calidad.
    • Incluir propiedades del documento.
  • Haz clic en Publicar para generar el PDF.
Otros formatos de exportación
  • XPS: Formato similar a PDF, ideal para impresión.
  • HTML: Para publicar en la web (guarda como página web).
  • TXT: Texto plano sin formato.
  • RTF: Formato enriquecido compatible con otros procesadores de texto.
  • ODT: Formato de OpenDocument para compatibilidad con LibreOffice.
Consejo: Para documentos legales o importantes, exporta a PDF con marcas de revisión y firma digital para garantizar la autenticidad.

Recuperación de documentos no guardados

Recupera documentos que cerraste sin guardar o que se perdieron por un error:

AutoRecuperación
  • Ve a Archivo → Abrir → Recuperar documentos no guardados.
  • Word mostrará una lista de documentos recuperables.
  • Selecciona el documento y haz clic en Abrir.
  • Guarda el documento inmediatamente para evitar perderlo nuevamente.
Configurar AutoGuardado
  • Ve a Archivo → Opciones → Guardar.
  • Activa Guardar información de AutoRecuperación cada X minutos.

  • Ve a Archivo → Opciones → Personalizar cinta.

  • Elige comandos de la lista y haz clic en Agregar.
  • Organiza los comandos arrastrándolos a la posición deseada.
Barra de herramientas de acceso rápido
  • Personaliza la barra de herramientas haciendo clic en la flecha desplegable al final.
  • Selecciona comandos para añadir (ej: Guardar como PDF, Imprimir, Deshacer).
  • Reorganiza los botones arrastrándolos.
  • Exporta o importa configuraciones para usarlas en otros equipos.
Consejo: Añade comandos como Guardar como PDF, Nuevo comentario o Traductor a la barra de acceso rápido para agilizar tu flujo de trabajo.

Desactivar complementos
  • Ve a Archivo → Opciones → Complementos.
  • Selecciona Complementos de COM y haz clic en Ir.
  • Desmarca los complementos que no uses (ej: barras de herramientas de terceros).
  • Reinicia Word para que los cambios surtan efecto.
Reparar Office
  • Ve a Panel de control → Programas → Programas y características.
  • Selecciona Microsoft Office y haz clic en Cambiar.
  • Elige Reparación rápida o Reparación en línea.
  • Sigue las instrucciones para completar el proceso.
Otras optimizaciones
  • Guarda documentos grandes en formato .docx en lugar de .doc.
  • Divide documentos muy largos en varios archivos.
  • Usa estilos en lugar de formato manual para reducir el tamaño del archivo.
  • Limpia el formato no utilizado con Inicio → Estilos → Inspector de estilos.
Actualizaciones
  • Mantén Word y Windows actualizados para tener las últimas correcciones de errores.
  • Ve a Archivo → Cuenta → Opciones de actualización.
  • Activa las actualizaciones automáticas para Office.

Módulo 14. Prácticas y Proyectos

Pon en práctica lo aprendido con ejercicios reales. Crea una carta formal, un informe académico, un folleto publicitario y un contrato editable. Estos proyectos te ayudarán a consolidar tus conocimientos y prepararte para situaciones reales.

Actividades prácticas por nivel

Ejercicios sugeridos para practicar según tu experiencia:

Nivel principiante
  • Carta formal: Redacta una carta con membrete, destinatario, cuerpo y firma. Usa estilos para los párrafos.
  • Currículum vitae: Crea un CV con secciones para experiencia, formación y habilidades. Usa viñetas y alineación.
  • Lista de tareas: Haz una lista de compras o tareas con viñetas y numeración.
Nivel intermedio
  • Informe académico: Diseña un informe con portada, índice, desarrollo, conclusiones y bibliografía. Usa estilos para generar la tabla de contenido.
  • Factura: Crea una factura con logo, tabla de productos, subtotales, impuestos y total. Usa fórmulas en la tabla.
  • Newsletter: Maqueta un boletín con columnas, imágenes y cuadros de texto.
Nivel avanzado
  • Folleto publicitario: Diseña un tríptico con imágenes, texto promocional y código QR. Usa columnas y ajustes de texto.
  • Contrato editable: Crea un contrato con campos de formulario (fechas, nombres, casillas de verificación) y protégelo.
  • Informe con gráficos: Importa datos de Excel, genera gráficos y analiza tendencias. Usa referencias cruzadas.
Proyectos integradores
  • Combina varias herramientas en un solo proyecto (ej: informe con tabla de contenido, gráficos, referencias y combinación de correspondencia).
  • Colabora con un compañero en un documento compartido en OneDrive.
  • Automatiza tareas repetitivas con macros.

Creación de documentos reales

Ejemplos detallados de documentos que puedes crear:

Carta formal
  • Encabezado: Incluye tu información y la del destinatario (nombre, dirección, fecha).
  • Saludo: Usa un saludo formal (ej: "Estimado/a [Nombre]").
  • Cuerpo: Redacta el mensaje en párrafos claros y concisos.
  • Despedida: Usa una fórmula de cortesía (ej: "Atentamente,").
  • Firma: Inserta una línea para firma o una imagen de tu firma escaneada.
Informe académico
  • Portada: Título, autor, fecha, logotipos institucionales.
  • Índice: Genera una tabla de contenido automática.
  • Desarrollo: Secciones numeradas con títulos y subtítulos.
  • Gráficos y tablas: Inserta datos de Excel y añade pies explicativos.
  • Bibliografía: Usa citas y genera la bibliografía automáticamente.
Folleto publicitario
  • Diseño: Usa columnas y cuadros de texto para organizar el contenido.
  • Imágenes: Inserta fotos de alta calidad y ajusta el texto alrededor.
  • Colores y fuentes: Elige una paleta llamativa pero legible.
  • Llamados a la acción: Incluye frases como "¡Contáctanos hoy!" o "Visita nuestra web".
  • Código QR: Añade un código que lleve a tu sitio web o redes sociales.
Contrato editable
  • Campos de formulario: Usa cuadros de texto para nombres, fechas y términos.
  • Casillas de verificación: Para opciones de sí/no (ej: "Acepto los términos").
  • Listas desplegables: Para seleccionar entre opciones predefinidas.
  • Protección: Restringe la edición para que solo se puedan completar los campos.
  • Firma: Deja espacio para firmas manuales o digitales.

Evaluación final de conocimientos

Pon a prueba lo que has aprendido con un proyecto integrador:

Proyecto integrador
  • Crea un informe anual para una empresa ficticia que incluya:
    • Portada con logo y título.
    • Índice automático.
    • Resumen ejecutivo.
    • Secciones con texto, tablas y gráficos.
    • Bibliografía y anexos.
  • Usa combinación de correspondencia para generar cartas personalizadas a los accionistas.
  • Protege el documento con una contraseña y añade una marca de agua "Confidencial".
Autoevaluación
  • Revisa tu proyecto con esta lista:
    • ¿El documento tiene un diseño profesional y coherente?
    • ¿Los estilos y la tabla de contenido funcionan correctamente?
    • ¿Las tablas y gráficos están bien formateados y son claros?
    • ¿La combinación de correspondencia generó documentos personalizados sin errores?
    • ¿El documento está protegido y listo para compartir?
  • Comparte tu proyecto con un compañero o mentor para recibir retroalimentación.
Beneficios:
  • Consolida todos los conceptos aprendidos en un solo proyecto.
  • Desarrolla habilidades para resolver problemas reales en entornos laborales.
  • Prepárate para certificaciones como Microsoft Office Specialist (MOS).
  • Mejora tu portafolio con proyectos demostrables.
